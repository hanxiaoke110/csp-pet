# CSP 助手 — 升级路线图

> 最后更新：2026-06-02

## 概述

CSP 桌面宠物学习助手升级路线，每阶段独立交付、不依赖下一阶段。所有联网服务使用 Cloudflare Workers + D1（免费方案），域名 `csp.fun`（~50 元/年）下的多个子域名。

## 域名规划

| 子域名 | 用途 | 阶段 |
|--------|------|------|
| `wish.csp.fun` | 许愿墙 API + 前端 | P1 |
| `workshop.csp.fun` | 精灵工坊 | P2 |
| `teacher.csp.fun` | 老师管理后台 | P3 |
| `rank.csp.fun` | 排行榜 | P4 |
| `parent.csp.fun` | 家长端 | P6 |

## 各阶段详情

### P1：许愿墙（联网验证）

**状态：** 方案已确认，待开发

**功能：**
- 学生提交精灵许愿，浏览+投票他人的许愿
- 投票权通过商城购买许愿票（100g/张，每周限 3 张）
- 提交门槛：Lv.10+ 宠物
- 隐私：学生互看昵称，老师看真实姓名（AES 加密）
- 老师管理页：查看真名 + 删除违规内容

**技术：** CF Workers + D1，域名 `wish.csp.fun`

**开发量：** ~7 小时

**目的：** 验证第一个联网功能，打通后端链路。为 P2-P3 积累经验

---

### P2：精灵工坊（素材生产力）

**状态：** 方案已讨论，待 P1 完成后启动

**功能：**
- 独立网页，老师用 AI 批量生成 spritesheet
- 输入文字描述 → AI 生成基础形象 → 扩展 7 行动画 → 拼成 spritesheet
- 导出 spritesheet.png + pet.json
- 其他老师浏览和下载已有素材

**技术：** Vite + React + CF Pages，AI 调 Qwen-Image-Edit-2511 API

**开发量：** ~3 天

**前提：** P1 已验证 CF Workers 可用；或等 Petdex 网页创作器上线

**备选：** 如果 Petdex 网页创作器上线且够好用，可能跳过此阶段

---

### P3：教师后台（教学闭环）

**状态：** 方案已讨论，待 P1+P2 完成后评估

**功能：**
- 老师登录 → 查看自己的学生列表、学习进度、答题情况
- 班级码机制区分不同老师的学生
- 学生端设置页输入班级码绑定

**技术：** CF Workers + D1，域名 `teacher.csp.fun`

**班级码方案：**
```
老师端（教练扩展）生成「班级码」
学生端设置页输入班级码绑定
App 联网时上报学习数据（带上班级码）
CF Workers 按班级码分库存储
真实姓名 AES 加密，仅老师可解密
```

**数据库设计：**
```sql
classes 表：class_code, teacher_name, created_at
students 表：device_id, class_code, nickname, real_name(encrypted), last_active
progress 表：device_id, quiz_score, quiz_date, pet_level, coins
```

**开发量：** ~1 周

**前提：** P1+P2 已验证后端；有老师主动提需求

---

### P4：班级排行榜（社交激励）

**状态：** 规划中

**功能：**
- 班级内排名、全校排名、全国排名
- 周榜、月榜、总榜
- 基于 P3 数据

**技术：** 复用 P3 后端，加排行查询

**开发量：** ~3 天

**前提：** P3 已上线，数据积累足够

---

### P5：跨班级赛事（活动运营）

**状态：** 规划中

**功能：**
- 限时编程赛、算法赛
- 老师组队，学生参加
- 复用 P3 后端

**开发量：** ~1 周

**前提：** P3 已上线，有足够多的老师和班级参与

---

### P6：家长端（外部监督 + 商业模式）

**状态：** 规划中

**功能：**
- 家长绑定孩子 → 看学习报告 → 设置奖励规则
- 家长付费订阅

**技术：** 独立前端 + 复用后端，域名 `parent.csp.fun`

**开发量：** ~1 周

**前提：** P3 已上线，家长有付费意愿
