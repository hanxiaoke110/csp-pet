# CSP 许愿墙 — 设计方案

> 最后更新：2026-06-02

## 概述

学生可以在 App 内提交新精灵许愿、投票支持他人的许愿。老师通过独立管理页面查看和删除。需保护学生隐私、防止刷票和垃圾内容。

## 权限体系

| 操作 | 门槛 | 说明 |
|------|------|------|
| 浏览许愿墙 | 无 | App内所有学生可看 |
| 投票 | 持有许愿票 | 商城购买：100g/张，250g/3张，每周限购3张 |
| 提交许愿 | Lv.10+宠物 | 约20-30天活跃用户才能发言 |

## 隐私设计

| 角色 | 看到什么 |
|------|------|
| 学生（公开） | 脱敏昵称 `小***` + 许愿内容 + 票数 |
| 老师（管理页） | 真实姓名 + 许愿内容 + 票数 + 删除按钮 |
| 服务端 | HMAC hash，不存明文个人信息 |

提交时学生需填写上课真实姓名（仅老师可见）。

## 投票机制

- **获取：** 商城购买许愿票（100g/张，250g/3张，每周限3张）
- **使用：** 点 👍 消耗1张票，同设备同许愿仅可投一次
- **防刷：** HMAC(deviceId, SECRET) 匿名签名，换设备成本极高

## 技术架构

```
App（智子→💡许愿）
  ├── 浏览：GET /api/wishes
  ├── 提交：POST /api/wishes
  └── 投票：POST /api/vote
       ↓ HTTPS
Vercel Serverless Functions（持有 Token）
  ├── 关键词过滤
  ├── 频率限制（每IP 3条/分钟）
  └── HMAC 签名验证
       ↓
Vercel KV 存储
  ├── wishes: {id, content, votes, author_hash, real_name, display_name, created_at}
  ├── votes: {wish_id, voter_hash}
  └── tickets: {device_hash, count, week}
```

## 内容审核

- 关键词黑名单（暴力/色情/政治），命中即拒绝
- 最少 2 个汉字，最多 60 字
- 同设备 24h 最多提交 3 条
- 老师可在管理页删除违规内容

## 老师管理页

- URL：`wish.csp.fun/admin`
- 认证：密码登录（密码存储在 Vercel 环境变量）
- 功能：查看所有许愿（含真名）、删除违规条目

## 开发量

| 模块 | 工时 |
|------|------|
| App 许愿页 UI | 3h |
| App 投票券商城集成 | 1h |
| Vercel Functions (CRUD+验证) | 3h |
| 关键词过滤+限流 | 1h |
| 管理页 (/admin) | 1h |
| 测试 | 1h |
| 总计 | ~10h（约1.5天） |

## 域名

Vercel 默认：`xxx.vercel.app`
可后续绑定自定义域名：`wish.csp.fun`

## 不做

- 不建用户系统（HMAC 匿名）
- 不存 IP / 设备型号 / 地理位置
- 不做评论/回复/通知
- 不接入第三方 AI 生成
