## 1. 概述

「智子试炼场」是 CSP 学习助手桌面端中「潜龙闭关」地牢模式的战斗系统升级。它将原有「答题扣 HP」的 quiz 模式，替换为**宠物回合制对战 + 编程题驱动技能释放**的新模式。

### 1.1 目标

- 让学生用编程知识驱动宠物战斗，提升学习动机
- 保留现有 8 个副本、40 个关卡、CSP 真题题库
- 新增宠物战斗属性、技能系统、元素克制、班级排行榜
- 面向中国中小学生，控制认知负荷

### 1.2 非目标

- 不做同学间宠物交易
- 不做单独的地牢签到奖励（复用现有签到系统）
- 不做实时 PVP
- 不做时间压力机制

---

## 2. 用户流程

```
打开「智子试炼场」
  ↓
选择出战宠物（从已拥有宠物中选 1 只）
  ↓
进入副本地图（8 个副本节点）
  ↓
选择关卡 → 显示守关 NPC 开场白
  ↓
进入战斗：选择技能 → 答题 → 释放技能
  ↓
战斗结束 → 评级结算 → 发放金币奖励
  ↓
查看班级排行榜
```

## 3. 核心战斗机制

### 3.1 战斗循环

每回合：

1. 根据双方速度决定先手
2. 先手方选择技能
3. 弹出对应知识点的 1 道编程题
4. 作答：
   - **答对**：技能正常释放
   - **答错**：技能以 60% 效果释放
5. 后手方行动
6. 循环直到一方 HP 归零

### 3.2 胜负条件

- 敌方 HP 归零：胜利
- 己方 HP 归零：失败
- 50 回合未分胜负：按剩余 HP 比例判定

## 4. 宠物属性

### 4.1 新增战斗属性

```ts
interface BattleStats {
  maxHp: number;      // 最大生命值
  currentHp: number;  // 当前生命值
  attack: number;     // 攻击力
  defense: number;    // 防御力
  speed: number;      // 速度
  element: PetElement; // 元素属性
}
```

### 4.2 数值公式

```
品级系数：普通 1.0，稀有 1.3，传说 1.6
等级成长：每级 +10%（HP/攻击/防御），+5%（速度）

maxHp   = floor(基础HP   × 品级系数 × 1.1^(等级-1))
attack  = floor(基础攻击 × 品级系数 × 1.1^(等级-1))
defense = floor(基础防御 × 品级系数 × 1.1^(等级-1))
speed   = floor(基础速度 × 品级系数 × 1.05^(等级-1))
```

### 4.3 伤害公式

```
伤害 = max(1, floor((attack × 技能倍率 - defense) × 元素克制系数 × 答题质量系数))
```

- 技能倍率：见技能表
- 元素克制系数：1.5（克制）/ 1.0（无关系）/ 0.7（被克）
- 答题质量系数：1.0（答对）/ 0.6（答错）

### 4.4 升级规则

- 战斗获得经验存入宠物经验池
- **手动升级**：玩家在宠物面板点击「升级」
- 升级后：`currentHp = maxHp`
- 播放升级特效（光芒、数字跳动、HP 回满动画）
- 与桌面宠物等级共享（同一 `OwnedPet`）

## 5. 技能系统

### 5.1 技能槽位

每只宠物固定 4 个技能，分别对应不同 CSP 知识点：

| 技能 | 知识点标签 | 基础倍率 | 效果 | 冷却 |
|---|---|---|---|---|
| 技能 1 | 语法基础 | 1.0× | 普通攻击 | 无 |
| 技能 2 | 流程控制 | 1.2× | 元素攻击 | 1 回合 |
| 技能 3 | 数据结构 | 1.4× | 攻击或护盾/回血 | 2 回合 |
| 技能 4 | 算法思维 | 1.8× | 大招 | 3 回合 + 每关限 2 次 |

### 5.2 防 spam 设计

- 强技能有冷却，无法连续释放
- 技能 4 每关最多 2 次
- S/SS 评级要求使用 ≥3 个不同技能
- 部分敌人对基础攻击有抗性

### 5.3 技能说明

每个技能按钮显示 tooltip：
- 技能名称和图标
- 对应知识点
- 伤害倍率
- 冷却状态
- 剩余可用次数

## 6. 元素克制

### 6.1 克制链

```
火 🔥 → 风 🌪️ → 地 🟫 → 水 💧 → 火 🔥
```

| 关系 | 效果 |
|---|---|
| 克制 | 1.5× 伤害 |
| 被克 | 0.7× 伤害 |
| 光 vs 任何元素 | 1.0×（无克制无被克） |

### 6.2 设计理由

- 4 元闭环易于记忆
- 光作为平衡型选择，没有复杂关系
- 与中国学生熟悉的 Pokémon/洛克王国属性克制一致

## 7. 副本与关卡

### 7.1 复用现有结构

- 保留现有 8 个副本、40 个关卡
- 复用 `dungeons.json` 的副本定义
- 复用 `question-mapping.json` 的题目映射
- 复用 `csp-exam-bank.json` 题库

### 7.2 敌方宠物配置

为每个关卡配置敌方宠物：

```json
{
  "id": "dungeon-01-stage-01",
  "enemyPet": {
    "speciesId": "glitch-bot",
    "level": 3,
    "tier": "common",
    "maxHpBoost": 1.0
  }
}
```

- 普通关卡：敌方等级 ≈ 副本推荐等级
- Boss 关：敌方等级 +2~3，品级提升

### 7.3 剧情文案

每个副本保留守关 NPC 开场白 + Boss 登场台词，采用智子 AI 世界观，中二热血风格。

## 8. 奖励与经济

### 8.1 随机金币奖励

| 场景 | 奖励范围 |
|---|---|
| 关卡胜利 | 10–20 金币 |
| 首次通关 | 30–60 金币（×3） |
| Boss 战胜利 | 额外 15–30 金币 |
| 评级 S | 额外 10–15 金币 |
| 评级 SS | 额外 15–20 金币 |
| 失败 | 无奖励 |

### 8.2 每周挑战次数

- 每周可挑战 5 次
- 次数用完后可继续练习，但无金币奖励

### 8.3 签到奖励

不新增独立签到。复用现有签到系统。

## 9. 评级系统

### 9.1 评级标准

| 评级 | 条件 |
|---|---|
| **SS** | 正确率 100%，剩余 HP ≥ 70%，使用全部 4 个技能，回合数 ≤ 期望回合 |
| **S** | 正确率 ≥ 80%，剩余 HP ≥ 50%，使用 ≥3 个不同技能 |
| **A** | 正确率 ≥ 70%，剩余 HP ≥ 30% |
| **B** | 正确率 ≥ 60% |
| **C/D** | 较低正确率或险胜 |

### 9.2 结算展示

结算页面显示：
- 获得的评级
- 正确率
- 剩余 HP
- 使用技能种类数
- 获得金币

## 14. 风险与应对

| 风险 | 应对 |
|---|---|
| 部分宠物图为动漫/IP 角色，有版权风险 | 新怪物逐步替换为原创/Kenney 素材；课堂内部使用风险较低 |
| 机制复杂度对低龄学生过高 | 通过新手引导、tooltips、简化技能说明降低门槛 |
| 学生只刷简单关卡 | S/SS 评级和排行榜激励挑战高难度 |
| 金币通胀 | 每周挑战次数限制 + 固定获取上限 |
