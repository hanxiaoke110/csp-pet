# 在线星象衣橱与典藏卡光效升级设计

日期：2026-10-07  
状态：设计已确认，尚未进入实施

## 1. 背景与目标

当前星象衣橱已有 24 个生肖、星座头像，但特色头像框、背景、挂件和动态特效数量较少。现有远程目录可以在线新增静态素材，却不能用数据描述新的粒子、扫光、视差和点击反馈；新增复杂动态效果仍要修改 CSS 并重新发版。

典藏卡也存在相同问题。芙宁娜使用独立背景、角色和文字层，移动时能产生明显景深；最新一批卡片把角色画在完整卡面里，只有整张卡倾斜，缺少芙宁娜那种空间层次。现有统一镭射层较弱，在复杂金色画面上不明显。

本项目目标是随下一版应用一次性建立通用、数据驱动的视觉引擎，并完成首批内容：

- 典藏卡恢复背景、角色、前景特效、文字的真实分层。
- 增强扫光、折射、粒子和鼠标反馈，同时坚持“主角第一，光效辅助”。
- 星象衣橱新增 20 件精品装扮，风格按炫酷 70%、可爱 30%。
- 获取方式按金币购买 70%、累计条件奖励 30%。
- 此后绝大多数新装扮、价格、条件和效果组合只需在线更新，不再频繁发布安装包。
- 保持本地存储、无登录体系和现有备份模式，不破坏老用户数据。

## 2. 非目标

- 不允许学生上传自定义图片或脚本。
- 不引入账号、云存档或新的登录系统。
- 不让云端执行任意 JavaScript、CSS 或着色器代码。
- 不把首批 20 件高清素材打进安装包。
- 不承诺任何未来完全未知的交互形式都能免发版；新效果应优先由既有通用原语组合，只有增加全新渲染能力时才需要升级应用。

## 3. 视觉原则

### 3.1 主角优先

- 头像、卡片角色的脸部、眼睛、关键服装和轮廓必须始终清晰。
- 强光主要沿边框、饰品、武器和背景运动。
- 角色附近只使用轮廓光、少量粒子和短促闪光。
- 静止状态自动收敛；鼠标移动或点击时短暂增强。
- 点击爆闪必须短于 650 毫秒，不能持续遮挡主体。
- 每个动态配置都要声明主体安全区，遮挡型图层默认不得进入安全区。

目标体验是“第一眼看见角色，第二眼发现卡片或装扮很炫”，而不是满屏光污染。

### 3.2 风格比例

- 14 件炫酷内容：强调星空、机甲、雷电、火焰、冰晶、空间与神殿氛围。
- 6 件可爱内容：强调猫爪、兔耳、奶茶、糖果、泡泡和幸运星。
- 男女学生均能找到适合自己的内容，避免全部偏向单一审美。

## 5. 在线衣橱架构

### 5.1 双目录兼容

为避免旧版应用误读新的动态字段，保留现有 `/wardrobe/catalog.json` 供旧客户端使用，下一版改读 `/wardrobe/v2/catalog.json`。

- v1 目录继续提供旧版能够安全显示的创始内容。
- v2 目录包含数据化图层、动画、条件规则和最低客户端能力版本。
- v2 客户端按“v2 远程目录 → v2 本机缓存 → v1 兼容目录 → 内置创始内容”的顺序回退。
- 只有确认旧版能够正确显示的静态商品，才允许同步写入 v1 目录。

### 5.2 数据模型

每件 v2 装扮包含稳定 ID、商品版本、分类、稀有度、获取方式、资源清单和渲染配置。渲染配置只允许组合白名单原语：

- `image`：普通透明图层。
- `particle`：星屑、火星、雪花、泡泡和碎片发射器。
- `orbit`：围绕头像旋转的物体或光环。
- `light-sweep`：沿指定角度移动的扫光。
- `glow`：呼吸、脉冲和轮廓辉光。
- `sprite`：受控帧动画或图集动画。
- `text-effect`：称号的渐变、描边、扫光和轻微故障。
- `pointer-parallax`：跟随鼠标或触摸的有限视差。
- `click-burst`：点击后的一次性短动画。

配置可以调整位置、锚点、缩放、旋转、透明度、颜色、混合模式、速度、持续时间、延迟、粒子数量、层级和安全区遮罩。所有数值在读取时限制到安全范围。

远程目录不得包含任意代码、任意 CSS、外部脚本或任意着色器文本。

### 5.3 条件规则

条件解锁使用白名单指标和组合规则表达，不再为每件商品单独增加判断函数：

- 支持 `>=`、`==` 等有限比较。
- 支持 `all`、`any` 组合。
- 指标包括累计答对数、好感度、典藏卡数量、不同迷宫完成数、副本覆盖数和成就数量。
- 不允许远程配置直接读写本地存储键名。
- 规则无法识别时显示“需要更新应用后查看”，不能误发奖励或导致页面崩溃。

## 6. 资源下载、缓存与备份

- 高清素材保存在 Cloudflare Static Assets，不进入桌宠安装包。
- 衣橱列表优先读取小缩略图；试穿、购买或穿戴时再下载完整素材。
- 每个文件声明字节数、SHA-256、媒体类型和版本。
- 下载完成且校验通过后才替换旧缓存；失败时继续显示旧版或安全占位图。
- 单件失败不能阻塞整个“我的”页面。
- 已穿戴素材在本地缓存中优先保留，清理缓存时不得先删除。
- 备份只保存稳定商品 ID、已拥有 ID 和当前穿戴状态，不保存大图片。
- 换电脑导入备份后，根据 ID 从 v2 目录重新下载；目录暂时不可用时保留状态并在下次联网恢复。
- 已经发放的商品不得从目录中物理删除；停售使用 `available: false`，保证备份恢复。

## 7. 动态效果运行时

### 7.1 渲染顺序

标准顺序为：背景远景 → 背景粒子 → 头像 → 头像框 → 挂件 → 前景粒子 → 昵称和称号。每一层可以声明有限视差，但头像本体始终保持最清楚。

### 7.2 性能降级

- 页面离开、窗口最小化或元素不可见时暂停动画。
- 使用合成友好的 `transform` 和 `opacity`，避免持续布局计算。
- 每个舞台设置总粒子数、模糊半径和活动图层上限。
- 检测持续低帧率后依次降低粒子数、模糊和前景动画，不降低头像清晰度。
- 系统启用“减少动态效果”时保留静态光泽和边框，关闭持续位移、旋转与爆闪。
- 点击动画设冷却时间，连续点击不能无限叠加特效。

## 8. 典藏卡升级

### 8.1 分层要求

每张卡至少包含：

1. 不含主角的完整背景层。
2. 与背景严格对齐的透明角色层。
3. 可选的前景特效或轮廓线层。
4. 独立文字层。

鼠标移动时背景与角色反向位移，前景幅度略大，文字保持稳定。不得用完整角色卡面再叠一张位置不一致的角色图，否则会出现双影。

### 8.2 光效要求

- 增加彩虹折射扫光、边框跑光、星芒、金粉和短促点击爆闪。
- 火、水、风、地、光分别采用火星、波纹、流线、晶屑和星芒等差异化效果。
- 角色脸部设置安全区，强光避开面部。
- 鼠标快速移动时适度增强，静止后收敛。
- 芙宁娜原版素材保持不变，作为分层和景深效果的质量基准。

衣橱与典藏卡共享粒子、扫光、视差和性能降级原语，但保留各自独立的目录与业务状态。

## 9. 安全与容量

- 默认只接受 `cards.cspstudy.top` 下的 HTTPS 素材。
- 素材类型限制为经过解码验证的 WebP、PNG 和受控图集；不接受远程 SVG 脚本内容。
- 单文件继续遵循 Cloudflare 25 MiB 上限，并设置更严格的产品预算。
- 缩略图建议不超过 150 KiB，普通完整素材建议不超过 1 MiB，复杂图集建议不超过 3 MiB。
- 目录和素材必须通过大小、校验码、尺寸、透明通道及引用完整性检查后才能发布。
- 目录保留上一版快照，发布后出现问题可以快速回滚。

## 10. 下一版范围与后续在线范围

下一版安装包包含：

- v2 在线衣橱目录读取器和通用视觉运行时。
- 数据化累计条件判断器。
- 下载、校验、缓存、回退和恢复机制。
- 典藏卡分层与动态光效升级。
- 兼容旧存档、旧装扮和旧典藏卡的迁移逻辑。

首批 20 件高清素材放在 Cloudflare，安装包只保留现有创始内容。

下一版完成后，以下内容通常无需再发版：

- 新增或修改头像框、背景、挂件、特效和称号。
- 调整价格、稀有度、说明和上架状态。
- 调整已有原语的颜色、速度、数量、强度与组合。
- 更换或修复美术素材。
- 新增白名单指标能够表达的条件奖励。

只有增加全新渲染原语、全新本地指标或破坏性目录格式时才需要更新客户端。

## 11. 验收标准

### 11.1 数据与兼容

- 老用户升级后无感进入，金币、成就、智子、典藏卡、已拥有装扮和穿戴状态不变。
- 新用户离线也能完成基础设置并使用创始装扮。
- v1 客户端不会读取 v2 动态目录，不因在线上新崩溃。
- v2 目录不可用时按本机缓存、v1 目录、内置内容顺序安全回退。
- 备份导入新电脑后，已拥有和已穿戴的在线装扮能够恢复。

### 11.2 视觉与交互

- 所有装扮在常见窗口尺寸下不遮挡头像脸部和昵称。
- 20 件商品都能在购买或领取前试穿，但试穿不能保存为已拥有。
- 金币商品显示价格，条件商品只显示明确获取条件。
- 典藏卡倾斜时能看出背景、角色和前景的相对位移。
- 强光、点击爆闪和属性粒子不影响角色辨识度。
- 键盘操作与减少动态效果模式可正常使用。

### 11.3 性能与故障

- 正常桌面电脑保持平滑动画；低性能设备触发自动降级后仍能顺畅操作。
- 页面切走和窗口最小化后不持续消耗粒子动画资源。
- 单件素材损坏、超时或校验失败时，只影响该商品并保留旧缓存。
- Cloudflare 暂时不可用时，已缓存与内置内容继续可用。
- 20 件在线素材不明显增加 Windows 安装包体积。

### 11.4 发布检查

- 在开发预览、Windows 安装包和老用户升级路径上分别测试。
- 校验目录版本、商品版本、全部资源哈希和实际字节数。
- 检查 14:6 风格比例、14:6 获取比例和全部价格、条件。
- 发布前保存 Cloudflare 上一版目录快照，发布后逐项线上回读。
