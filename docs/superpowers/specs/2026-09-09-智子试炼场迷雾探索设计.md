# 智子试炼场迷雾探索与赛季装备设计

> 日期：2026-09-09
> 状态：8 个副本、40 张普通关首通迷宫已实现；重复探索与每周排名迷宫仍属后续阶段
> 适用范围：智子试炼场第二阶段
> 核心原则：学习优先、规则透明、旧存档兼容、低配置可用、本地资源优先

## 1. 最终决策

| 项目 | 决策 |
|---|---|
| 地图形态 | 真正的方格迷宫，包含墙壁、通道、岔路、死路与少量环路 |
| 技术方案 | ROT.js 负责生成、视野和寻路；首版迷宫使用轻量原生 Canvas，现有 Phaser 继续负责答题战斗 |
| 普通迷宫 | 每个普通关卡首通解锁，共 8 个副本、40 张算法生成地图 |
| 首通次数 | 免费，不消耗探索次数 |
| 重复探索 | 消耗探索次数，可获得普通探索奖励 |
| 每周排名 | 所有人使用相同地图、题目、事件和规则，按有效步数排名 |
| 普通地图时长 | 目标 6-8 分钟，首次引导 8-10 分钟，最长尽量不超过 12 分钟 |
| 每周地图时长 | 目标 8-12 分钟 |
| 题目 | 选择、判断、程序阅读、程序填空均支持；普通地图避免连续大型代码题 |
| 装备位 | 武器、护甲、法器三个功能位；配饰仍是独立的纯外观系统 |
| 装备范围 | 本赛季整个智子试炼场；影响移动公平的效果在排名迷宫中暂停 |
| 背包 | 8 格探索背包、3 个快捷道具位、3 个装备位 |
| 分解材料 | 仅使用一种材料“器魂碎片”，避免材料系统膨胀 |
| 排行榜 | 战斗榜保持不变，新增独立“每周迷雾榜” |
| 联网策略 | 移动和事件本地保存，完成排名地图时只上传一次成绩 |
| 美术策略 | 全部新增资源自行生成并本地打包，不复用许可不明的开源游戏素材 |
| 安装包 | 本阶段不删除商城智子，新增资源预算 3-5MB |

## 2. 目标与非目标

### 2.1 目标

- 将关卡胜利后的单一返回流程扩展为有路线选择的轻量探索。
- 让答题决定封印、奖励、增益和战斗状态，而不是成为装饰事件。
- 让装备具有整个赛季的收集价值，同时不替代学习能力。
- 为班级提供公平、可解释、不拼手速的迷宫竞赛。
- 保证探索模块异常时不阻塞现有答题、关卡、金币和排行榜。

### 2.2 非目标

- 不做实时开放世界、即时动作战斗或真人 PVP。
- 不做头盔、鞋子、戒指等十几个装备位。
- 不做装备强化失败、耐久维修、套装和多材料锻造。
- 不做装备交易、赠送和付费抽取。
- 不让任何装备自动答题、排除答案或跳过知识封印。

## 3. 玩家流程

```text
普通关卡战斗胜利
  -> 战斗结算
  -> 首通时显示“进入迷雾探索 / 稍后探索”
  -> 进入对应关卡迷宫
  -> 寻找并完成三个知识封印
  -> 出口开启
  -> 选择直接离开或继续探索支路
  -> 出口统一结算
  -> 返回副本并继续下一关
```

- “稍后探索”始终存在，探索不反向锁住已经完成的关卡。
- 未完成地图可从副本入口继续，不重新扣次数、不重新生成事件。
- 旧玩家按已完成关卡自动获得对应探索入口，不要求重新战斗。
- 探索模块加载失败时提供“安全返回副本”，不修改任何进度和经济数据。

## 4. 迷宫规则

### 4.1 地图规格

- 普通地图建议 11x9 或 13x9，可行走格约 50-65 个。
- 最短有效路线约 20-28 步，正常探索约 30-45 步。
- 地图必须包含入口、出口、三个知识封印和至少一个可选支路奖励。
- 首张地图按探索距离划分为“水庭外环、机关回廊、玄武灵台”三域，每域固定一道知识封印和至少一个可选事件。
- 完成本区知识封印后才开放下一区域；未开放边界不扣步数，只显示明确提示。
- 生成后执行连通性、出口可达性、封印可达性与最短路径校验。
- 地图由 `seasonId + dungeonId + stageId + playerId` 生成固定种子。
- 每周排名地图由 `seasonId + weekId` 生成全员统一种子。

### 4.2 移动与迷雾

- 点击相邻可走格移动，支持键盘方向键。
- 点击较远的已探索格可自动寻路，每经过一格仍正常计步。
- 当前格和周围一圈完全可见，走过区域保留暗色轮廓，其他区域保持迷雾。
- 移动、揭雾、拾取与事件结果每步立即保存。
- 排名地图禁用传送、穿墙、步数减免和额外视野等破坏公平的效果。

## 5. 探索次数与任务联动

### 5.1 次数来源

- 每个普通关卡的首通迷宫免费，不消耗次数。
- 每周一基础发放 3 次。
- 完成每日任务可领取 1 次，每周最多通过每日任务获得 3 次。
- 完成整周任务额外领取 2 次。
- 每周最多 8 次，未使用次数不结转。
- 第一版不开放金币购买探索次数。

### 5.2 扣除与恢复

- 创建一张新的重复探索或排名地图时扣除 1 次。
- 恢复已有地图、查看背包、规则和排行榜不扣除。
- 资源加载或地图生成失败时自动返还。
- 异常关闭后恢复原地图，不重复扣除。
- 主动放弃时不返还，并显示二次确认。
- 所有领取来源使用唯一凭证，防止重复发放。

## 6. 事件与题目

### 6.1 普通地图事件比例

| 类型 | 建议比例 | 说明 |
|---|---:|---|
| 普通道路 | 35% | 路线判断与迷宫节奏 |
| 答题事件 | 28% | 普通问题、知识封印、试炼石碑 |
| 金币或经验 | 8% | 进入待结算奖励，受现有上限保护 |
| 恢复与功能道具 | 7% | 恢复、照明、净化、罗盘等 |
| 装备 | 7% | 武器、护甲或法器 |
| 减益陷阱 | 6% | 短期、可见、可净化，不永久扣属性 |
| 宝箱 | 4% | 支路和死路深处的额外奖励 |
| 商人 | 3% | 使用器魂或通用金币购买物品 |
| 精英事件 | 2% | 高难题组或强化战斗 |

首张地图额外教学事件：

- “天机玉简”标记最近一道未完成封印并提示知识点，不直接揭开通路，也不能代替答题。
- “灵脉岔路”只能选择一次：稳妥通道暂存 3 金币；试炼通道暂时缩小视野，下一道封印答对暂存 8 金币。
- 路线选择、玉简标记和奖励均写入探索存档，退出重进不会重复触发或重复结算。

### 6.2 题目规则

- 每张地图有三个必须完成的知识封印，全部解除后出口才开放。
- 普通选择、判断题使用轻量弹窗。
- 程序阅读、程序填空使用完整“试炼石碑”界面，显示代码、子题和选项。
- 题目优先匹配当前副本和关卡的知识点，后期综合副本允许混合真题。
- 答错写入现有错题本和弱点统计，不直接终止探索。
- 答错知识封印增加 5 个排名惩罚步数，但仍可继续。
- 同一地图题目固定；新地图从可用题池去重抽取。
- 装备和提示不能自动提交答案或改变正确答案。

## 7. 装备、背包与器魂

### 7.1 装备位

| 部位 | 定位 | 数值边界 |
|---|---|---|
| 武器 | 攻击、元素伤害、连击触发 | 总伤害加成最高约 15% |
| 护甲 | 护盾、减伤、抵抗减益 | 总减伤最高 12% |
| 法器 | 照明、恢复、净化、事件增益 | 排名地图暂停移动公平类效果 |

- 第一、二、三张首通迷宫依次教学并解锁武器、护甲、法器。
- 装备在本赛季整个智子试炼场生效，包括普通关、Boss、弱点复习和自由练习。
- 新赛季后旧装备进入赛季图鉴或转换为纪念资源，不继续叠加属性。
- 配饰保持纯外观，不占功能装备位。

### 7.2 背包

- 3 个装备位、3 个快捷道具位、8 个探索背包格。
- 消耗品可堆叠，装备不可堆叠。
- 背包满时必须选择替换、使用、分解或暂不拾取，禁止静默销毁。
- 获得新装备时显示与当前装备的数值和适用范围对比。

### 7.3 品级与分解

| 品级 | 颜色 | 分解器魂 |
|---|---|---:|
| 普通 | 灰白 | 2 |
| 稀有 | 蓝 | 5 |
| 史诗 | 紫 | 12 |
| 传说 | 金 | 25 |

- 商店购买装备的回收价值不超过购买价的 25%。
- 器魂用于商人兑换装备、有限次数刷新和重选附加效果。
- 剩余器魂在副本完成时转换为少量试炼 EXP，不大量兑换金币。
- 装备中物品、史诗和传说装备分解时必须二次确认。
- 永久配饰、钥匙和任务物品不可分解。

### 7.4 首批装备设计

武器共 10 种，每种元素 2 种：

| 元素 | 武器 | 主要方向 |
|---|---|---|
| 地 | 玄岩重锤、镇岳短戈 | 稳定伤害、答对后护盾 |
| 火 | 赤焰短剑、熔芯法杖 | 直接增伤、有限灼烧 |
| 风 | 青岚双刃、逐风弓 | 连击触发、冷却辅助 |
| 水 | 玄潮长枪、寒泉法杖 | 能量恢复、少量治疗 |
| 光 | 曜光长枪、星辉刃 | 净化、正确连击增益 |

护甲共 5 种：玄甲、赤鳞、风羽、潮纹、曜光，各对应一种元素主题。

法器首批 8 种：探路罗盘、长明灯、净化玉符、回响镜、连击印、护心轮、星图仪、机关钥盘。

消耗品首批 6 种：照明灯芯、净化符、恢复药、探路针、宝箱钥匙、事件重选券。

## 8. 奖励与经济

- 普通首通地图预计获得 10-25 通用金币、少量试炼 EXP 和一件装备或道具。
- 地图内显示“本次已发现奖励”，到达出口后统一正式结算。
- 通用金币继续调用现有统一金币账本并受日/周上限保护。
- 随机事件不直接增加段位积分。
- 三个知识封印全部答对时提高出口知识宝箱品质。
- 重复探索可以获得普通资源，但主要首通奖励不可重复领取。
- 中途退出可恢复；主动放弃才清理本次未结算奖励。

## 9. 排行榜

### 9.1 页面结构

```text
[战斗赛季榜] [每周迷雾榜]
[班级榜]     [全服榜]
```

- 现有战斗榜、分数、赛季数据和在线说明保持不变。
- 普通关卡迷宫不参与排名。
- 每周迷雾榜只使用统一地图、统一题目、统一事件和统一基础规则。
- 装备品级、获得金币和随机掉落不直接计入排名。

### 9.2 排序规则

```text
有效步数 = 实际移动步数 + 答错知识封印数 x 5
```

1. 有效步数少者优先。
2. 步数相同，答题正确率高者优先。
3. 正确率相同，探索完成度高者优先。
4. 仍相同则并列，不使用完成时间打破并列。

排行榜行同时显示实际步数、有效步数、答题结果和探索率。排名玩法不鼓励拼手速。

### 9.3 服务端写入

- 新增每周探索成绩表，唯一键为 `deviceHash + seasonId + weekId`。
- 只在完成地图时提交一次，服务器保留本周最佳成绩。
- 不上传每一步移动、背包内容和迷雾状态。
- 服务端校验周种子、地图版本、最低可能步数、封印数量和数值范围。
- 排行榜说明继续走在线配置，本地保留离线默认文案。

## 10. 统一帮助与首次引导

- 探索次数旁显示帮助图标，并明确当前数量、来源、消耗和下次重置日期。
- 鼠标悬停显示摘要，点击、触摸或键盘聚焦打开完整说明。
- 地图、步数、封印、装备位、背包、品级、器魂、Buff/Debuff、商人和排行榜均使用统一帮助组件。
- 单件装备 tooltip 必须显示名称、品级、效果、触发条件、剩余次数、生效范围和失效条件。
- 规则文案可在线更新，但在线配置不能改变实际数值和经济逻辑。
- 首次进入迷宫显示三步引导：移动揭雾、解除封印、支路奖励。
- 引导只强制显示一次，并可从帮助入口重新打开。

## 11. 技术架构

### 11.0 开源复用结论

本阶段采用“复用成熟底层算法、自研业务规则和表现层”的方式，不复制完整开源游戏。

| 项目 | 许可与状态 | 可复用内容 | 结论 |
|---|---|---|---|
| [rot.js](https://github.com/ondras/rot.js) | BSD-3-Clause，约 2.7k Star，功能稳定 | `EllerMaze`/`Digger` 地图生成、`PreciseShadowcasting` 视野、`AStar` 寻路、种子随机 | **直接作为 npm 依赖使用** |
| [Phaser](https://github.com/phaserjs/phaser) | MIT，项目现有版本为 3.90 | Canvas 渲染、输入、摄像机、Tween、粒子、对象池 | **继续使用现有依赖，不升级大版本** |
| [labyrinth-game](https://github.com/luckyr13/labyrinth-game) | MIT，小型 Phaser 3 + TypeScript 示例 | 点击移动、路径展示、迷宫交互思路 | 仅参考，不复制整体实现 |
| [Dungeon Crawler Now](https://github.com/JohnVonDrashek/dungeon-crawler-now) | MIT，Phaser 3 + TypeScript | 迷雾、背包、掉落、存档模块的职责划分 | 仅参考架构，不引入代码和素材 |
| [EasyStar.js](https://github.com/prettymuchbryce/easystarjs) | MIT，约 1.9k Star | 异步 A* 寻路 | 暂不引入；rot.js 已覆盖当前寻路需求 |

选择边界：

- `rot-js` 只导入地图、FOV、路径和 RNG 所需模块，验证 Vite tree-shaking 后的实际增量。
- 地图生成结果先转换为项目自己的 `ExplorationMap` 数据结构，业务层不得直接依赖 ROT 内部对象。
- 地图生成、事件分布、最短路线和周榜种子都必须有确定性测试；同一版本、同一种子必须得到相同结果。
- Phaser 只负责画面、输入和动效，探索规则由纯 TypeScript 服务计算，避免画面帧率影响计步和结算。
- 背包、装备、答题、金币、排行榜和存档与本项目规则强绑定，保留自研，不额外引入完整游戏框架。
- 开源项目的图片、音效、字体和地图素材一律不复制；所有新增美术与 UI 由本项目重新设计和生成。
- 发布包附带第三方许可清单，保留 BSD-3-Clause 与 MIT 的版权声明。

### 11.1 模块边界

```text
dungeonStore
  玩家、关卡、战斗、错题、段位、金币上限

explorationStore
  地图种子、位置、迷雾、事件、步数、待结算奖励

trialEquipmentStore
  赛季装备、背包、器魂、快捷栏、装备状态
```

- 不把探索状态继续堆入现有 `dungeonStore`。
- 从战斗页面抽取纯展示 `QuestionRenderer`，探索和战斗各自管理提交逻辑。
- 装备效果通过统一钩子执行：移动、答对、答错、战斗开始、伤害、受击和战斗结束。
- 所有地图生成、奖励计算、装备效果和排名计算优先实现为可单元测试的纯函数。

### 11.2 路由与页面

- 新增 `/explore/:dungeonId/:stageId`。
- 新增探索主界面、事件弹窗、试炼石碑、背包抽屉、装备对比、商人、出口结算和帮助弹窗。
- 战斗结算页首通时增加“进入迷雾探索”和“稍后探索”。
- 副本入口显示可探索、探索中和已完成状态。

## 12. 存档、迁移与安全

- 探索存档使用独立版本号和独立 key；单个探索存档损坏不能影响其他 Store。
- 地图由种子重新生成，只保存位置、已发现格、已处理事件和背包，单图目标 2-5KB。
- 每次移动和物品操作后立即保存，防止异常关闭丢失。
- 安全备份纳入探索和赛季装备数据，并验证导入后的 schema。
- 旧存档缺少新字段时安全初始化，不修改原有智子、金币和关卡数据。
- 已通关老玩家自动获得探索入口，但不自动发放探索奖励。
- 更新或资源加载失败时提供安全返回，绝不回退关卡进度。

## 13. 美术资源清单

### 13.1 总体风格

- 主题：山海机关秘境与数字修行，不使用通用西式地牢套皮。
- 视角：正上方或轻微 2.5D 的方格迷宫，路径必须清楚，装饰不能遮挡格线。
- 画面：延续现有青铜、灵光、机关与山海异兽语言，提高明暗区分。

## 14. UI 资源与页面清单

1. 探索 HUD：次数、步数、封印、待结算奖励、装备槽、背包入口、帮助入口。
2. 迷宫画布：迷雾、当前位置、可移动提示、事件标记和自动寻路。
3. 事件弹窗：事件结果、奖励、Buff/Debuff 和继续按钮。
4. 试炼石碑：支持 choice、reading、fillBlank 三种题目结构。
5. 背包抽屉：8 格背包、3 快捷栏、分类、容量和范围标签。
6. 装备详情：属性、触发、范围、失效、剩余次数和分解产物。
7. 装备比较：当前与新装备并排，支持替换、分解和暂不拾取。
8. 商人界面：购买、回收、有限刷新和余额展示。
9. 出口结算：路线、实际/有效步数、答题、探索率、奖励和失效物品。
10. 次数领取：每日任务和周任务的明确领取状态与防重复提示。
11. 每周迷雾榜：战斗/迷雾模式切换、班级/全服范围和规则说明。
12. 统一帮助弹窗：短摘要、完整规则、在线更新时间和本地兜底状态。
13. 首次引导：移动揭雾、知识封印、支路奖励三步遮罩。
14. 异常恢复：继续探索、安全返回、存档修复和资源加载失败状态。

所有界面必须适配当前 800x500 最小窗口、950x560 默认窗口和 Windows 125%/150% 缩放，不依赖只有鼠标悬停才能完成的操作。

## 15. 资源与安装包预算

当前 `public` 资源约 99MB，其中智子精灵约 66MB、课程与题库约 26MB，试炼场美术约 7MB。迷雾阶段预算：

| 资源 | 预算 |
|---|---:|
| 共享迷宫图集与 8 套主题覆盖 | 1.5-2.5MB |
| 装备、道具、事件与品级图标 | 0.8-1.2MB |
| 商人、装饰与轻量效果纹理 | 0.5-0.8MB |
| UI 辅助素材 | 0.2-0.5MB |
| 总新增目标 | 3-5MB |

- 本阶段不删除、下架或远程化商城智子，防止旧存档缺图。
- 不将商城资源优化与迷雾功能放在同一批改动中。
- 后续若优化安装包，优先评估精灵 PNG 转 WebP、构建重复文件和按需资源包，并单独完成 Windows 兼容测试。

## 17. 验收底线

- 探索失败或损坏不能影响现有关卡、智子、金币和战斗。
- 40 张地图均可达，三个封印和出口均不会被墙或事件阻断。
- 首通免费、任务次数和失败返还均不可重复领取。
- 排名地图对所有人使用相同内容，移动类装备不影响排名。
- 每件装备和道具都有可见图标、完整 tooltip、范围与失效说明。
- 普通地图 80% 的测试流程在 10 分钟内完成。
- 新增资源控制在 5MB 目标内，低性能模式下无持续高负载动画。
- 所有新增状态可安全备份、导入和从旧存档初始化。
