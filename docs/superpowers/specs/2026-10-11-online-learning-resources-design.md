# 学习资料在线目录与飞书逐课讲义设计

**日期：** 2026-10-11  
**状态：** 待用户复核  
**内容方案：** 飞书文档承载正文，Cloudflare 静态 JSON 承载资料目录

## 1. 背景与问题

v1.7.48 移除了旧“课程”和“AI 教练”功能，但同时也移除了“学习资料”页中的“常规课课程目录”。目前项目状态为：

- `course-card-index.json` 仍保留 P1–P69 的 69 个飞书逐课链接；
- `lessons.json` 仍有 P1–P77 的课程内容；
- P70–P77 尚未加入逐课飞书索引；
- Cloudflare 线上仍保留 69 课的 `course-card-index.json`；
- 当前学习资料页只读取安装包内的 21 个知识点和 21 个专题，不再读取逐课索引；
- 当前学习资料页没有接入线上目录、本机缓存和离线回退。

本次不恢复旧课程系统，只恢复“逐课学习资料”。学习资料不记录完成进度，不发放金币、经验或成就。

## 2. 目标

1. 恢复 P1–P69 现有飞书资料入口，后续补全 P70–P77。
2. 本次客户端发布后，新增课程资料、改标题、改链接、调顺序和上下架不再需要发版。
3. 修改已有飞书文档正文时，不需要更新客户端或 Cloudflare 目录。
4. 断网、Cloudflare 故障或远程 JSON 异常时，页面仍可以使用上一次成功的目录或安装包内置目录。
5. 全部目录请求使用 Cloudflare 静态资源，不消耗 D1、KV 或 Worker 写入额度。

## 3. 非目标

- 不恢复旧课程的题目、解锁、下载、完成状态和奖励逻辑。
- 不恢复 AI 教练或 AI 配置。
- 不将讲义大图、PDF 或飞书正文打入安装包。
- 不建设新的服务端数据库、登录系统或教师管理后台。
- 不改动孩子已有金币、经验、智子、试炼、迷宫、成就和历史课程记录。

## 4. 用户界面

“学习资料”页调整为三个一级分类：

1. **课堂资料**：默认分类，展示 P1–Pn 逐课讲义。
2. **知识点救援**：展示现有 21 张知识卡及与题目的关联。
3. **专题复习**：整合现有一轮专题和二轮学习路径。

### 4.1 课堂资料展示

- 按 C1–C4 阶段折叠展示，默认展开当前有内容的第一阶段；
- 每个阶段标题显示资料数量和课号范围；
- 每节课显示课号、标题、简介、标签和更新日期；
- 支持按 `P69`、`69`、课程标题和标签搜索；
- `ready` 显示“打开资料”；
- `coming_soon` 显示“制作中”，若已有飞书占位文档仍可打开；
- `hidden` 不展示；
- 需要班级码的条目显示锁标识，未绑定时复用现有班级码提示；
- 页面不显示进度条、完成按钮、奖励或连续学习数据。

### 4.2 打开飞书

- Tauri 桌面应用通过系统浏览器打开飞书链接；
- 普通浏览器调试环境使用新标签打开；
- 打开失败时显示可理解的错误，并提供“复制链接”；
- 不在客户端 WebView 中嵌入飞书登录页，避免登录、Cookie 和兼容性问题。

## 5. 在线目录架构

### 5.1 文件

Cloudflare 提供两个独立文件：

- `https://cards.cspstudy.top/course-data/learning-catalog.version.json`
- `https://cards.cspstudy.top/course-data/learning-catalog.json`

资料目录使用独立版本号，不复用已退役的课程正文 `version.json`，避免题库、旧课程数据和资料卡片互相触发更新。

### 5.2 目录结构

```json
{
  "schemaVersion": 1,
  "catalogVersion": 1,
  "updatedAt": "2026-10-11T00:00:00+08:00",
  "navigationUrl": "https://scncdgmg7m6w.feishu.cn/docx/...",
  "lessons": [
    {
      "id": "lesson-material-p001",
      "lessonNo": 1,
      "title": "基础框架",
      "stage": "C1",
      "description": "C++ 程序的基本结构与运行顺序。",
      "tags": ["C++", "入门"],
      "feishuUrl": "https://scncdgmg7m6w.feishu.cn/docx/...",
      "status": "ready",
      "requiresClassCode": false,
      "updatedAt": "2026-10-11"
    }
  ]
}
```

规则：

- `id` 和 `lessonNo` 一经发布不再改变；
- 新课程只追加新 ID，不复用删除课程的 ID；
- `lessonNo` 必须为正整数且全局唯一；
- `feishuUrl` 只接受 HTTPS 飞书文档链接；
- `stage` 只允许 C1、C2、C3、C4；
- 未知字段允许客户端忽略，便于未来在线扩展；
- 目录上限先设为 500 条，超限或格式异常时拒绝覆盖本机缓存。

## 6. 加载与缓存

资料页采用“本机先显示，远程后刷新”：

1. 启动时先验证并显示本机缓存；
2. 没有缓存时显示安装包内置的 P1–P69 基础目录；
3. 后台请求 Cloudflare 版本文件；
4. 版本号增加时拉取新目录；
5. 通过格式验证后用新目录替换页面并写入本地缓存；
6. 请求失败、超时或新目录非法时，继续使用旧缓存或内置目录，不显示全页报错。

缓存只包含资料元数据，不包含飞书文档正文。预计仅几十 KB，不影响存档和安装包体积。

### 6.1 备份边界

- 线上目录和本机缓存都是可重新下载的公开数据，不进入学生备份；
- 备份和恢复不改动资料目录；
- 历史课程完成记录继续原样保留，但学习资料页不读取它们。

## 7. 飞书内容和权限

### 7.1 文档规则

- 每节课使用一个稳定飞书文档；
- 文档标题与目录课号一致；
- 后续只更新文档内容，不反复新建文档，以保持 URL 稳定；
- 文档底部保留“返回学习资料总导航”链接；
- 长文、代码和例题使用飞书正文，不制作成不可搜索的长图。

### 7.2 权限门禁

发布前必须将文档设为“获得链接的人可阅读”。在线目录发布脚本执行以下检查：

- 课号不重复、ID 不重复；
- 必填字段完整；
- URL 必须为允许的飞书 HTTPS 域名；
- `ready` 条目不能为空链接；
- 记录无 Cookie 环境的链接检查结果。

飞书可能对自动检查请求返回登录跳转，因此自动检查不能完全代替真实未登录浏览器验收。正式发布新文档时，仍需对新增链接做一次无痕窗口抽查。

## 8. 发布工作流

### 8.1 修改已有课程内容

1. 在原飞书文档编辑内容；
2. 检查阅读权限；
3. 完成。

无需发布客户端，无需更新 Cloudflare 目录。

### 8.2 新增课程

1. 新建飞书文档并设置公开只读；
2. 在源目录追加课号、标题、链接等元数据；
3. 将 `catalogVersion` 加一；
4. 运行资料目录校验；
5. 部署 Cloudflare 静态资源；
6. 用无痕浏览器验收新文档。

无需发布客户端。

### 8.3 下架或暂未完成

- 下架：改为 `hidden`；
- 预告：改为 `coming_soon`；
- 恢复上架：改为 `ready`；
- 每次变更都增加 `catalogVersion` 并重新部署静态目录。

## 9. 旧数据迁移

1. 将现有 `course-card-index.json` 的 P1–P69 转换为新目录结构；
2. 保持原飞书 URL 不变；
3. 新目录内置进安装包，作为首次启动和断网回退；
4. P70–P77 在飞书文档就绪前可显示为 `coming_soon`，不伪造或猜测飞书 URL；
5. 现有 `knowledge-points.json` 和 `knowledge-lectures.json` 保持不变，仅调整页面分组；
6. 旧版学生数据无需迁移。

## 10. 错误处理

- 远程版本请求超时：使用缓存或内置目录；
- 远程目录格式错误：不覆盖旧缓存，记录本地警告；
- 单个条目异常：目录整体拒绝更新，防止孩子看到部分错乱数据；
- 飞书打开失败：保留页面，提供重试和复制链接；
- 缓存写入失败：当次仍可使用在线目录，不影响其他功能；
- 资料服务不可用：不阻塞应用启动、选择题、真题、OJ、试炼和迷宫。

## 11. 验证与测试

### 11.1 数据测试

- 新目录的结构验证；
- 课号和 ID 重复拦截；
- 飞书 URL 域名白名单；
- `ready` / `coming_soon` / `hidden` 过滤；
- 500 条上限；
- P1–P69 迁移后的课号、标题和 URL 与旧索引完全一致。

### 11.2 加载测试

- 无缓存时使用内置目录；
- 远程版本较新时更新并缓存；
- 远程超时、404、非 JSON 和非法字段时回退；
- 远程目录旧于本地时不降级；
- 旧缓存损坏时自动回退内置数据。

### 11.3 界面测试

- 三个分类正常切换；
- 阶段折叠、课号搜索、标题搜索和标签搜索；
- 不显示课程进度和奖励文案；
- 飞书链接打开和复制链接兜底；
- 小窗口和 1366×768 屏幕不出现横向溢出；
- 学习资料页故障不影响其他路由。

### 11.4 发布验收

- Cloudflare 版本文件和目录均返回 200；
- 远程目录更新后，已安装客户端不升级即可看到新课；
- 完全断网时仍可看到 P1–P69 内置目录；
- 无痕浏览器抽查 P1、P69 和当次新增课程的飞书阅读权限。

## 12. 发布边界

本次需要发布一个客户端版本，内容包括：

- 新学习资料分组与逐课入口；
- 线上目录、缓存、内置回退和数据验证；
- 资料目录校验和 Cloudflare 发布流程。

此后以下变更均不需要发布客户端：

- 修改飞书文档正文；
- 新增逐课资料；
- 改课程标题、简介、标签、阶段或更新日期；
- 更换飞书链接；
- 设置资料制作中、隐藏或重新上架；
- 改变班级码限制标记。
