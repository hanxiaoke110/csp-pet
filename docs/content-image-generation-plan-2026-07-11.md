# 智子学习资料生图计划（2026-07-11 评估版）

## 0. 结论先行

当前不需要一次性生成 100 多张图片。已有资料足以支撑第一阶段内容：

- 21 张专题知识卡图片可以直接复用，不重新生成。
- 21 份补充专题讲义作为知识卡的详细正文来源。
- 68 份课程讲义 PDF、71 份教案 Markdown、71 份 AI 寓言作为课程内容和故事来源。
- 第一轮只新增约 30 张图片，验证效果后再扩展到 40-50 张。
- 图片放在飞书资料文档中，客户端只保存轻量链接；后续补图不需要重新发版。

图片的职责是“吸引注意、建立记忆锚点、提示易错点”，不是替代讲义。长文字、完整代码、公式解释和答案必须放在飞书文档正文中。

## 3. 逐步执行计划

### 阶段 0：内容对齐，不生图

目标：建立“课程课号 → 教案 → 寓言 → 知识卡 → 题目 → 飞书文档”的映射。

具体工作：

1. 为 P1-P68 读取课程标题、教学目标、核心概念、常见错误和代表题。
2. 为 P1-P71 读取寓言标题、故事冲突和一句话寓意。
3. 把 21 个专题讲义与知识卡图片建立一一对应关系。
4. 标出已有图、可直接使用的图、需要补图的知识点。
5. 检查所有图中文字是否有公司名、机构名、网址或不适合学生的内容。
6. 先完成 P45/P70/P71 的资料缺口登记，不用未核实内容生正式图。

阶段产物：一份内容映射表和一份“可直接上传 / 需要生图 / 暂缓”的清单。

### 阶段 1：风格校准，生成 4 张样张

先只生成 4 张，确认画风、角色、文字可读性和飞书展示效果：

1. P1《小六头一回开锣》：入门寓言插画。
2. P8《岔路口的守门人》：分支结构寓言插画。
3. P14《钟楼里的小沙弥》：for 循环记忆插画。
4. C1 入门阶段：课程线/Boss 入口封面。

验收标准：

- 中国中小学生一眼能看懂场景，不幼稚、不阴暗、不拥挤。
- 角色和配色可连续复用，不能每张图像换了一个产品。
- 中文只保留短标题和短口诀，无乱码。
- 缩小到学习资料卡片尺寸仍能看清主体。
- 不出现公司、品牌、机构、网址、二维码、水印。

样张不通过时只调整风格模板，不进入批量生成。

## 4. 生图与飞书的落地方式

每张图片生成后按以下流程处理：

1. 原图保存在项目外的素材归档目录，保留课号、类型、版本和提示词。
2. 人工检查事实、文字、角色一致性和敏感内容。
3. 需要文字和代码的部分在飞书正文重新排版，不依赖图片中的文字。
4. 图片上传到对应飞书讲义/寓言/复盘文档。
5. 总导航只维护稳定的飞书文档链接，不把图片打进客户端。
6. 客户端的 `learning-resources.json` 只保存文档链接、类型、课号和状态。

这样后续替换图片、补充讲义、增加 CSP-J 复赛内容，都不需要重新安装客户端。

## 5. 生成规范

- 画布优先竖版 2:3，适合飞书文档和资料卡。
- 统一使用“明亮漫画 + 编程冒险 + 学习卡”的视觉语言。
- 可复用角色：学生程序员、CPU 小伙伴、代码精灵、试炼场守门人。
- 蓝/黄/绿作为主色，红色只用于错误提醒；避免满屏深色或单一紫色。
- 每张图只表达一个知识点或一个故事冲突。
- 图片内中文控制在标题、短口诀、短标签范围内。
- 代码、公式、复杂流程图由飞书正文或客户端渲染，不能依赖生图准确写出。
- 所有成图必须去除公司名、机构名、原资料水印、网址和二维码。
