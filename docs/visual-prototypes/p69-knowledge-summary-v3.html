栈 · 知识总览

最后进入的元素，为什么最先离开？
目标：看懂栈顶操作，会用 C++ stack 解决典型问题。

1灵魂规则

栈（Stack）是一种只能在同一端进行插入和删除的线性结构。

后进先出 LIFO：最后进去，最先出来。

A
B
C
push A → B → C
→
A
B
pop 得到 C

2五个基本操作

push(x)把 x 放到栈顶
pop()删除栈顶元素
top()查看栈顶，不删除
empty()判断栈是否为空
size()查看元素个数
#include <stack>
stack<int> s;
s.push(10);
s.push(20);
cout << s.top(); // 20
s.pop();           // 删除 20

栈顶操作通常都是 O(1)。

3跟着栈跑一遍

依次执行：push(4), push(7), push(9), pop()

[4]栈顶 4
[4,7]栈顶 7
[4,7,9]栈顶 9
[4,7]弹出 9

读取顺序从左到右，真正能操作的始终是最后一个元素。

4它能解决什么？

括号匹配表达式求值函数调用撤销操作深度优先搜索

共同点：任务暂时压住，最后到来的通常要优先处理。

5高频陷阱

  • 空栈调用 top() 或 pop()
  • 误以为 top() 会删除元素
  • 把栈当成先进先出的队列
  • 试图直接访问栈底或中间元素

6做题三步法

  1. 先判断当前动作是“放入”还是“取出”
  2. 只追踪栈顶，不必反复扫描全部元素
  3. 取出或查看前，先用 empty() 判空

一分钟自测

A、B、C 依次入栈；执行一次 pop() 后再 push(D)，此时栈顶是谁？

答案

D

C 被弹出，D 最后入栈。
