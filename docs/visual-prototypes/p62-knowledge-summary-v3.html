计数排序 · 知识总览

不反复比较，能不能直接数出来？
目标：理解 cnt 数组，会判断计数排序什么时候划算。

1核心模型

计数排序：先统计每个值出现几次，再按值从小到大输出。

原数组
312301

逐个读取

→
计数表
01次
12次
21次
32次

cnt[值]

→
有序输出
011233

按下标顺序

2最小代码

for (int x : a)
    cnt[x]++;

for (int v = 0; v <= m; v++)
    while (cnt[v]--)
        cout << v << ' ';

把“值”当作数组下标，把“次数”存进格子。

3什么时候用？

整数值域较小重复值较多成绩统计频次统计

如果有负数，先整体加偏移，让它们变成非负下标。

4复杂度

时间：O(n + m)，n 是数据量，m 是值域大小。

空间：O(m)，需要开出计数数组。

值域越大，空格子越多，越不划算。

5高频陷阱

  • cnt 未初始化，旧数据会混进来
  • 数组下标越界：值大于 m
  • 负数没有加偏移量
  • 值域太大，空间爆炸

6做题三步法

  1. 先找最小值、最大值和值域
  2. 确认能否把值映射成下标
  3. 统计次数，再按下标顺序输出

一分钟自测

100 个数，取值范围是 0 到 1 亿，适合直接用计数排序吗？

答案

不适合

空格子太多，空间远大于数据量。
