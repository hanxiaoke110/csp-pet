2最小代码

for (int x : a)
    cnt[x]++;

for (int v = 0; v <= m; v++)
    while (cnt[v]--)
        cout << v << ' ';

本质：把“值”当作下标，用数组记录出现次数。

适用条件

  • 整数或能映射为整数
  • 值域 0…m 较小
  • 重复值较多

复杂度

时间：O(n + m)

空间：O(m)

n 为数据量，m 为值域。

易错提醒

  • cnt 未初始化
  • 负数未增加偏移量
  • 值域太大浪费空间

成绩统计排名桶数组

计数数组也能统计频次。

只有 100 个数，但取值范围是 0 到 1 亿，适合计数排序吗？

答案

不适合。

要开一亿多个计数格，空间远大于数据量。

P69 栈

本课目标：掌握“后进先出”，只在栈顶完成插入、删除和查看。

2五个基本操作

push(x)把 x 放到栈顶
pop()删除栈顶元素
top()查看栈顶，不删除
empty()判断栈是否为空
size()查看元素个数
stack<int> s;
s.push(10);
s.push(20);
cout << s.top(); // 20
s.pop();

核心规则

后进先出（LIFO）

只能操作栈顶，不能直接访问栈底或中间元素。

复杂度

push / pop / top

通常都是 O(1)

只改变或查看栈顶。

易错提醒

  • 空栈调用 top/pop
  • 误以为 top 会删除元素
  • 把栈当成先进先出的队列

常见应用

括号匹配表达式求值函数调用深度优先搜索

一分钟自测

A、B、C 依次入栈，连续 pop 两次，栈顶是谁？

答案

A。 弹出 C、B，剩下 A。

口诀：只碰栈顶，后进先出；取前判空。智子知识卡 · P69
