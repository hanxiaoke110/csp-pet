### 核心概念图（主视觉区）
建议用一张**字符串操作对照图**：左侧是 C 风格字符数组 `char s[100]`，右侧是 C++ string 类。中间用函数对照表连接。

风格：代码对比风格，左侧深底老式风格，右侧浅底现代风格。

### 核心要点（卡片上显示 5 条）

| # | 图标 | 要点 |
|---|------|------|
| 1 | 📝 | **字符数组 vs string**：`char s[100]` 是 C 风格，以 `'\0'` 结尾；`string s` 是 C++ 类，功能更强更安全 |
| 2 | 📏 | **常用函数**：`.length()` / `.size()` 获取长度；`s[i]` 访问单个字符；`+` 拼接字符串 |
| 3 | 🔍 | **子串与查找**：`.substr(pos, len)` 提取子串；`.find(str)` 查找子串位置，找不到返回 `string::npos` |
| 4 | 🔄 | **比较与转换**：`==` / `!=` / `<` 按字典序比较；`stoi(s)` 字符串→整数；`to_string(n)` 整数→字符串 |
| 5 | ⌨️ | **输入输出**：`cin >> s` 遇空格停止；`getline(cin, s)` 读整行含空格；`getchar()` 逐字符读取 |

### 一句话总结
> **字符数组 '\0' 结尾，string 类是升级版。substr 截取、find 查找、getline 读整行。**

### 智子气泡
💬 *"处理文本就靠它了，string 比字符数组好用多啦！"*

### 主视觉参考

下方：操作对照表
| 操作 | C 风格 | C++ string |
|------|--------|------------|

| 比较 | `strcmp(a,b)` | `a == b` |
| 拷贝 | `strcpy(a,b)` | `a = b` |
