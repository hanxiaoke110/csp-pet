## 卡片内容

### 标题
**枚举与模拟**

### 核心概念图（主视觉区）
建议用一张**"暴力枚举"示意图**：展示一个密码锁（3位数字，000-999），用循环嵌套的方式逐个尝试。旁边配一段简单的枚举代码。

风格：左侧是密码锁/骰子组合等生活化场景，右侧是代码，用箭头连接。

### 核心要点（卡片上显示 5 条）

| # | 图标 | 要点 |
|---|------|------|
| 1 | 🔓 | **枚举思想**：把所有可能的情况一一列举出来，逐个检查是否符合条件。也叫"暴力法"（Brute Force） |
| 2 | 🔁 | **枚举框架**：用循环嵌套遍历所有可能的取值范围。一层循环枚举一个变量，n 层嵌套枚举 n 个变量 |
| 3 | 🎯 | **模拟思想**：按照题目描述的规则，一步步模拟执行过程。不追求巧妙算法，追求"做对" |
| 4 | ⚡ | **可行性判断**：枚举前先估算枚举量。每秒约 10⁷~10⁸ 次运算，枚举量太大（>10⁸）会超时 |
| 5 | ✂️ | **剪枝优化**：如果当前部分枚举已经不可能满足条件，提前跳出。好的剪枝可能把 10⁹ 降到 10⁶ |

### 一句话总结
> **枚举就是"一个一个试"，模拟就是"照着规则做"。先确保正确，再考虑优化。**

### 智子气泡
💬 *"不会巧妙方法？那就老老实实枚举！"*

## 生图指引

### 主视觉参考
密码锁场景：一个 3 位数字密码锁，显示 `0 0 0` → `0 0 1` → ... → `9 9 9`，用箭头表达"逐个尝试"的过程。旁边加代码：
```cpp
for (int i = 0; i <= 9; i++)
  for (int j = 0; j <= 9; j++)
    for (int k = 0; k <= 9; k++)
      if (check(i, j, k)) { /* 找到了！*/ }
```

### 配色
- 主色：`#2196F3`（天蓝）
- 循环变量用不同颜色标注（i=红, j=绿, k=蓝）
- 密码锁表盘用灰色，正确密码高亮金
