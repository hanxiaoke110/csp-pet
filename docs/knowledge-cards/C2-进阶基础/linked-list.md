## 卡片内容

### 标题
**链表**

### 核心概念图（主视觉区）
建议用一张**数组 vs 链表对比图**：上方是数组（连续格子，像一排连在一起的火车车厢），下方是链表（分散的节点+箭头指针，像用绳子串起来的散落珠子）。

每个链表节点画成两个格子：`[数据 | →]`，最后一个指向 `NULL`。

### 核心要点（卡片上显示 5 条）

| # | 图标 | 要点 |
|---|------|------|
| 1 | 🔗 | **链表结构**：每个节点包含数据域 + 指针域（指向下一个节点）。头指针指向第一个节点，尾节点指向 NULL |
| 2 | ⚡ | **插入删除 O(1)**：只需修改指针指向，不需要像数组那样移动大量元素 |
| 3 | 🐌 | **查找访问 O(n)**：不能像数组那样通过下标直接访问，必须从头指针逐个遍历 |
| 4 | 📊 | **数组 vs 链表**：数组 → 连续存储、下标访问 O(1)、插入删除 O(n)；链表 → 分散存储、访问 O(n)、插入删除 O(1) |
| 5 | 🔄 | **变种**：单向链表（只有 next）、双向链表（有 prev + next）、循环链表（尾节点指向头节点） |

### 一句话总结
> **链表牺牲随机访问换插入删除效率。结点 = 数据 + 指针，头进尾出逐个走。**

### 智子气泡
💬 *"数组是连排座位，链表是用绳子串起来的散座！"*

## 生图指引

### 主视觉参考
上方：数组 `[A|B|C|D|E]` 五个连续格子
下方：链表 `head → [A|→] [B|→] [C|→] [D|→] [E|NULL]` 分散节点 + 箭头

再画一个"插入操作"示意：在 B 和 C 之间插入 X：
- Before: `[B|→ C]`
- After: `[B|→ X] [X|→ C]`（只改了两个指针！）
