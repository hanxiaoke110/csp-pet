## 卡片内容

### 标题
**结构体与类**

### 核心概念图（主视觉区）
建议用一张**结构体"包装盒"示意图**：左边是散落的变量 `string name; int age; double score;`，右边是一个叫 `Student` 的结构体盒子把它们装在一起。盒子标签上显示 `struct Student { ... }`。

旁边再展示：如何创建变量 `Student s1;` 和访问成员 `s1.name`。

### 核心要点（卡片上显示 5 条）

| # | 图标 | 要点 |
|---|------|------|
| 1 | 📦 | **结构体 struct**：把多个不同类型的变量"打包"成一个新类型。成员默认 public（公开访问） |
| 2 | 🏛️ | **类 class**：和 struct 类似，但成员默认 private（私有）。面向对象编程的基础 |
| 3 | 🔑 | **成员访问**：用 `.` 运算符：`变量.成员名`。指针用 `->`：`ptr->成员名` |
| 4 | 🛠️ | **构造函数**：创建对象时自动调用的初始化函数，名字与类名相同，无返回类型。可以有多个（重载） |
| 5 | 📋 | **struct vs class**：C++ 中 struct 和 class 几乎一样，唯一区别：struct 默认 public，class 默认 private |

### 一句话总结
> **struct 打包不同类型的数据，`.` 访问成员。构造函数自动初始化，一个类可以有多个构造函数。**

### 智子气泡
💬 *"把相关的数据打包在一起，代码更清晰！"*

## 生图指引

### 主视觉参考
左侧：散落的变量 → 右侧：struct 盒子（3D 风格）
```cpp
struct Student {
    string name;    // 姓名
    int age;        // 年龄
    double score;   // 分数
};
Student s1;
s1.name = "小明";  // 用 . 访问
s1.age = 12;
s1.score = 95.5;
```
盒子用带标签的卡片视觉，每个成员一行。
