# 智子知识卡 · 通用设计规范

## 形象参考

**智子形象**：蓝色麒麟（Blue Qilin），参考图路径：
- 高清原图：`pet-sprites-remote/2d/blue-qilin.png`（2686×2686，2.6MB）
- 发布预览：`public/pet-sprites/previews/blue-qilin.png`（60KB）

智子是 CSP 学习助手的 AI 导师形象，设计为蓝色麒麟，风格偏向科技感+亲和力。
知识卡上智子应作为"讲解者"出现，指向/介绍知识点内容。

---

## 知识卡尺寸与格式

| 属性 | 规格 |
|------|------|
| 尺寸 | **1200×1600px**（竖版卡片，适配手机全屏查看） |
| 格式 | PNG / WebP（WebP 质量 85%） |
| 命名 | `kp-{card-id}.webp`，如 `kp-computer-hardware.webp` |
| 托管 | **飞书文档**（图片嵌入飞书知识卡文档，不存本地） |
| 输出 | 每张卡 `<400KB`，上传到对应的飞书知识卡文档中 |

> ⚠️ 知识卡图片最终托管在**飞书文档**中，通过 `knowledge-points.json` 中的 `feishuCardUrl` 字段引用。生好的图请上传到对应的飞书文档，然后更新 `feishuCardUrl`。

## 智子形象使用指南

智子在每张知识卡中以"讲解导师"身份出现，放置在卡片右下角区域（约 200×200px），
配上对话气泡，气泡内容为针对该知识点的学习提示（20 字以内）。

**示例气泡文案**：
- "记住这个，考试常考！"
- "理解原理比背答案重要哦~"
- "多写代码才能真正掌握！"

智子形象风格：扁平化、线条清晰、蓝色主调、表情友善。
