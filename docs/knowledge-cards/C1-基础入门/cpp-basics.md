## 卡片内容

### 标题
**C++语言基础**

### 核心概念图（主视觉区）
建议用一张**C++程序结构图**：左侧是源代码（带高亮的 `#include <iostream>` / `int main()` / `return 0`），右侧是变量声明、数据类型、运算符的"工具箱"展示。

风格：代码编辑器风格，深底浅字展示样例代码，旁边配上概念标签。

### 核心要点（卡片上显示 5 条）

| # | 图标 | 要点 |
|---|------|------|
| 1 | 📝 | **标识符规则**：由字母、数字、下划线组成，不能以数字开头，不能是关键字（如 `int`、`return`、`if`） |
| 2 | 📦 | **基本数据类型**：`int`（整数）、`float/double`（小数）、`char`（字符）、`bool`（true/false） |
| 3 | 🔢 | **变量声明与赋值**：`int a = 10;` 声明整数变量 a 并赋值为 10。变量必须先声明再使用 |
| 4 | ➗ | **运算符**：算术(`+ - * / %`)、关系(`> < == !=`)、逻辑(`&& || !`)。`%` 是取余，`/` 整数除会截断 |
| 5 | ⌨️ | **输入输出**：`cin >> 变量` 输入，`cout << 内容` 输出。`endl` 换行。需 `#include <iostream>` |

### 一句话总结
> **变量先声明后使用，整数除法会截断。cin 读、cout 写，分号结尾不能忘。**
