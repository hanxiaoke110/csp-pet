# 典藏卡窗口与头像转头修复

状态：2026-10-25 已修复源码并完成验证，尚未发布桌面新版。

## 典藏卡自适应

在实际应用 1000×600 CSS 像素窗口中复现：卡片高 549px，按钮底部到 642.5px，超出可见区域。原弹窗布局高度限制只作用于外层，卡片按 61vh 取宽后又乘 1.5，未预留操作区。弹窗也没有挂到 body，在有 filter/backdrop-filter 的窗口皮肤下可能额外受父容器裁切。

修复：复用 ModalPortal 挂到 body，关闭按钮单独预留位置，卡片按剩余窗口高度取尺寸、宽度不超过容器。弹窗限制最大高度并允许内容滚动；窄窗口切换单列；操作区可换行。背面字号和间距随卡片宽度缩放，保留翻面、鼠标景深与自动赏卡。

## 灵蛇、逐风马

检查 v2 的 5×5 原始图集：灵蛇各行的左右列顺序相反；逐风马只有抬头的前两行反向，平视和低头行顺序正常。新 getAvatarDirection 根据这两款 v2 图集选取对应列，不镜像图像本身，上下行不变。其他头像沿用原映射；后续正确重制的 version≥3 素材不再套用旧图修正。鼠标离开时取消排队的动画帧，防止复位后又被旧鼠标位置覆盖。
