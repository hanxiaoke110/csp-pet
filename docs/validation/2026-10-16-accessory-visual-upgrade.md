# Six accessory visual upgrade — 2026-10-16

Scope: local implementation only. No desktop release, push, cloud deployment or price changes.

## Rendering

- Full-stage SVG coordinates replace fitting square marks into flat halo boxes.
- Rear / portrait / front stacking creates real orbit occlusion without covering the face.
- Clear halo: bright bounded outline, dark contrast edge, soft breathing light.
- Prism: counter-rotating geometry, gold ticks, side crystals and gold outer arc.
- Stars and lanterns: elliptical orbit, depth-dependent scale/opacity, solid silhouettes and accent colors.
- Comet and pixel trails: movement-history samples, direction-aware rear emission, bounded particle lifetime and capacity, fading after movement stops, no emission at rest or on teleports.
- DOM and Phaser share orbit and history geometry. No engine dependency, WebView or raster asset added.
- Hiding, sleeping, reduced motion and teardown cancel/simplify motion. Existing drag hitbox unchanged; decorations ignore input.
- Six existing IDs, prices, ownership, per-pet slots and backup format are unchanged.

## Online authoring

Existing color, accent, count and duration fields remain supported. Optional `visual.size` accepts finite numbers from 0.6 to 1.4 (default 1); arbitrary executable metadata remains rejected. Compatible primitive updates can be distributed through the existing catalog after the desktop renderer ships. New primitive types still require a client update.
