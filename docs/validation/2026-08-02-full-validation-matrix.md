### 新发现汇总

1. 学习分析：用户确认不需要（2026-08-02）；已从 `teacher-app/index.html` 删除 `AnalyticsPanel` 死代码（69 行，本地已改、语法校验通过，待部署 CF Pages）。实际 UI 中无该入口（纯死代码），不会误点 404。

3. 登录轮换 token 会导致多设备互踢（设计如此，验证时旧 token 会失效，属预期）。
4. **dialog confirm ACL（P1，已修复 2026-08-02）**：`dialog:default` 只含 allow-message/save/open，**confirm 命令需要独立的 `dialog:allow-confirm`，v1.7.22-1.7.25 均缺失**——孩子端 1.7.25 实测仍报 `plugin: dialog confirm not allowed by ACL`（触发点：AdminPage 删除许愿的原生 `confirm()`）。修复：capabilities 显式补 `dialog:allow-confirm`（cargo check 通过，生成 capabilities 已确认），并把 AdminPage 的 `confirm()` 换成应用内确认弹窗，彻底消除对原生 confirm 的依赖。**随下一版发版生效；1.7.25 及更早版本无法通过升级解决（需发新版）**。剩余 5 处 `alert()`（工坊/知识卡）由 allow-message 放行，不报 ACL，但若想彻底不依赖原生对话框可一并换成应用内提示。
