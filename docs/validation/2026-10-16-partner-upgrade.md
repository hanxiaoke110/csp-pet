## 审查中修复的关键问题

- 同倍率窗口缩放仍需刷新 Phaser 父容器边界，不能只改像素倍率。
- Canvas 字体不可重复提高内部文字分辨率，否则字号会异常放大。
- 品质增益不能沿用旧品质倍率导致速度也增加。
- 交易失败后的恢复不能反而完成扣款；日志先记录回滚意图，完整写入后才记录提交。
- 旧窗口不能覆盖另一窗口的新培养、获取或回收进度；恢复与拆解不能生成可重复返还记录。
- SQLite 异步读取后重读本地权威快照，避免恢复已经花掉的星砂。
- 新交易、日志恢复、资料载入、备份使用同一 Web Lock；storage 刷新不恢复另一窗口的活跃日志。不能使用新交易锁的环境不扣新款，清洁旧存档读取和备份恢复仍兼容。
- 配饰按原装备槽位、永久所有权和引擎支持度过滤；未知特效不假装成其他特效。兼容当前图元的新目录 ID 允许在线扩展。
- 配饰在线目录后台刷新，开战不等待可选装饰网络请求。
