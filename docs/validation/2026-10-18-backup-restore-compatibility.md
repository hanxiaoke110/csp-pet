# 旧备份恢复兼容修复（暂未发版）

## 已确认原因

- 实际提供的旧备份能通过解析和摘要预览，但含五条 `dungeon_healing_recent_` 中文知识点记录。记录由治疗答题页正常生成；共享事务仅允许 ASCII 键，在写入之前拒绝整个恢复操作。
- 备份层未区分数据校验拒绝和写入失败，将其统一显示为“请检查磁盘空间”。
- 同一备份还包含约 2.6 MiB（约 2.7 MB，UTF-16 计量）的旧题库缓存。仅修正中文键后，在模拟 5 MiB localStorage 配额的隔离测试中，整体恢复日志仍可能超额。

## 实现

- 共享本地事务兼容同一 `csp_` / `dungeon_` 命名空间内的中文、空格和 C++ 标点键名。这是平面 localStorage 键，不是文件系统路径；仍限制长度、数量、数据类型、控制字符和事务日志保留键。
- 校验和提交使用同一校验函数；恢复预检查拒绝时明确报告数据校验失败，不再归因磁盘空间。
- 旧题库缓存不纳入新备份，也不从旧备份重新写入；不删除当前机器的缓存，不过滤最近题目记录或学生进度。
- 保留可恢复日志与失败回滚行为；实际写入失败提示可能的应用存储配额或权限问题。UI 不再在所有失败情况下笼统承诺“现有数据未受影响”，改为提示保留备份和当前数据。

## 验证

- 先通过失败测试复现中文键拒绝，再验证恢复成功。
- 先用真实备份复现 5 MiB 配额失败，再验证缓存排除后恢复成功。
- 原始隐私备份仅在本机隔离环境读取，不加入 Git、不上传服务器、不导入真实应用数据；原文件字节未修改。
- 三项私有验收通过：模拟 5 MiB 配额下覆盖已有存储、恢复到空存储、通过真实智子 store 重新加载。十只智子、金币余额、375 条完成记录、五条中文最近题目记录均保留，智子 ID/物种/昵称/等级一致。
- 可移植测试新增 14 项：中文原样恢复、中文日志提交/回滚恢复、失败回滚、非法命名空间/控制字符/超长键拒绝、校验错误提示、缓存排除与配额限制等。
- 全量 96 个测试文件、666 项测试通过；主程序与迷宫生产构建（含 TypeScript 检查和打包裁剪）及 `git diff --check` 通过。分包大小与静态/动态导入的既有提示仍保留，无构建错误。

## 边界

- 未执行 Windows 原生实机安装和恢复验收；隔离测试与生产构建不能替代实机测试。
- 未修改版本号、安装包或线上升级指针；需要后续客户端修复版才能让已安装 v1.7.53 的用户获得此修复。
- 本次修复针对截图中的备份恢复失败；若还存在另一个启动崩溃，应依据其独立错误详情继续排查。
