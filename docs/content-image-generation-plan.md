## 2. 图片类型

每张图只承担一个明确用途：

| 类型 | 用途 | 建议文字量 | 是否优先 |
|---|---|---:|---|
| 主讲义卡 | 每节课核心知识点，一眼看懂本课学什么 | 20-45 字 | 高 |
| 易错复盘卡 | 课后复盘、错题提醒、边界条件 | 20-40 字 | 高 |
| 寓言插画卡 | 配合现有 AI 寓言，用故事降低理解门槛 | 10-30 字 | 中 |
| 章节/Boss 封面 | 智子试炼场、阶段挑战、月度复盘入口 | 5-20 字 | 中 |
| 流派/奖励图 | 强化养成、活动、徽章和赛季奖励 | 0-15 字 | 低 |

注意：

- 不把整节课内容塞进一张图。
- 不在图里放公司名、机构名、二维码、网址。
- 代码、详细讲解、例题放飞书/Cloudflare 文档，图片只做兴趣入口和记忆锚点。

## 9. 风格规范

推荐统一风格：

- 视觉：明亮、游戏化、漫画讲义卡、像闯关奖励卡。
- 受众：中国中小学生，避免太幼稚，也避免大学教材感。

- 角色：学生程序员 + 可爱的 CPU/键盘/代码精灵/试炼场元素。
- 版式：标题区 + 2-3 个知识块 + 底部挑战条。
- 字数：主图尽量 20-45 字，最多不超过 60 字。
- 禁止：公司名、机构名、二维码、网址、水印、密集代码、长段文字。

## 14. 飞书链接预置策略

> 目标：让客户端当前版本可以长期使用。后续讲义图 / 寓言图做好后，只需要上传到飞书文档或修改远程索引，不需要频繁更新客户端。

核心原则：

- **客户端只保存资源索引，不保存大图。** `public/course-data/learning-resources.json` 只存标题、类型、课号、阶段、标签、缩略图 URL、资料 URL、是否需要班级码、`status` 等轻量字段。
- **飞书文档可以提前建好。** 即使内容还没做，也可以先建一个飞书占位文档，把链接写进索引，`status` 标为 `coming_soon`。
- **内容为空时使用 `coming_soon` 状态。** 卡片按钮显示「制作中」，但仍允许点击打开占位链接，因为飞书占位页后续会直接更新，孩子无需更新客户端就能看到正式内容。
- **图片上传到飞书后，孩子无需更新客户端即可查看。** 索引里的 URL 指向飞书文档，文档内容更新对客户端透明。缩略图 `thumbnailUrl` 同理，可后续填入飞书公开图链。
- **正式发版前 `example.com` 必须替换。** 当前所有 `url` / `thumbnailUrl` 仍是 `https://example.com/...` 占位，这是发版阻塞项（见第 12 节）。
- **远程索引未来可接 Cloudflare / Gitee / 飞书公开 JSON。** `src/components/resources/LearningResourcesPage.tsx` 中的 `REMOTE_RESOURCE_INDEX_URL` 常量当前为空（不启用远程索引，使用本地兜底）；未来填入公开 JSON 地址后，客户端会优先拉远程索引、失败回退本地，从而做到「改远程索引 = 全量客户端即时生效」，连热更新都不必。

字段与状态约定（与 `learning-resources.json` 的 `_schema` 一致）：

| 字段 | 说明 |
|---|---|
| `lessonNo` | 课程序号 P1-P71，非课程类资源可省略 |
| `status` | `ready` 按钮「打开」；`coming_soon` 按钮「制作中」（仍可点击）；`hidden` 不展示 |
| `thumbnailUrl` | 缩略图外链，空则显示占位（不破图） |
| `requiresClassCode` | `true` 需绑定班级码后才可打开（门禁逻辑不变） |
| `url` | 资料外链，当前 `example.com` 占位，发版前必须替换 |

远程索引兜底逻辑：

- `REMOTE_RESOURCE_INDEX_URL` 非空：先 `tauriFetch` 远程 JSON（走 Tauri HTTP 插件绕过 WebView CORS），格式校验通过则使用远程资源；失败 `console.warn` 并回退本地 `/course-data/learning-resources.json`。
- `REMOTE_RESOURCE_INDEX_URL` 为空：直接使用本地索引。
- 远程失败、格式异常都不白屏：远程失败回退本地，本地也失败显示错误态 + 返回按钮，资源全 `hidden` 或过滤后为空显示空状态。

落地节奏建议：

1. 先在飞书按 P1-P16 建好主讲义卡占位文档（标题对齐 `lessons.json`），把 `url` 从 `example.com` 换成飞书公开链接，`status` 保持 `coming_soon`。
2. 风格样张图（第 6 节 8 张）做完后，上传到飞书文档内，并把对应 `thumbnailUrl` 填上飞书公开图链，`status` 改为 `ready`。
3. 上述两步都不需要发版——只要把 `learning-resources.json` 推到远程索引（或下一次热更新），孩子下次启动即生效。
