# v1.7.54 发布说明

日期：2026-10-20（Asia/Shanghai）。状态：发布准备中，尚未切换正式更新指针。

## 本次内容

- 修复旧版备份合法中文键及过时题库缓存引起的恢复失败；恢复使用写入屏障和事务恢复保护，避免旧内存覆盖刚恢复的存档。
- 数据库损坏或锁定时不再自动删除数据库、重建空账号；独立校验本地与数据库副本，异常状态不误判成首次领养。
- 典藏卡、衣橱、付费改名与工坊购买同步保存钱包及所得物品，持久化失败时不发布虚假的成功状态。
- 题库大缓存迁出 localStorage，减少与存档争抢配额；缓存损坏或更新失败可回退有效缓存或内置题库。
- 联网补偿码使用同设备稳定回执，响应丢失后可重试，客户端奖励及去重记录一同保存；优秀码保持本地验证，历史已核销码不自动重发。
- 非经济性的迷宫进度/徽章断网暂存与退避重试；服务端并发更新不会把较好的成绩降回较差成绩，不补发战斗金币或经验。
- 修复迷宫内专注运行时、多智子精灵动画相互影响、修改姓名时清空未提交手机号的问题。
- 教师登录加入原子限速，重置密码撤销旧会话；保留旧令牌兼容，不启用会话定时过期开关，不迁移教师密码格式。
- 更新兼容范围内的依赖安全补丁，增加 Windows 自动化及原生数据库故障发布门禁。
