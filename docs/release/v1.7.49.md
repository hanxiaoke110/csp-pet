## 我的星途

- “我的”默认页从每日小目标改为“我的星途”：11 项永久累计任务，不要求每日打卡，也不会过期。
- 已有的选择题、迷宫封印与通关、智子试炼关卡进度会自动计入对应任务；达标后由孩子自行领取。
- 一次性学习区焕新礼为 200 金币、100 EXP、2 份普通食物；11 项任务全部领取合计另有 1110 金币和 820 EXP。
- 任务目录从 Cloudflare 静态素材加载，失联时使用本机内置目录；后续可对现有进度指标增加任务，无需每次发版。
- 奖励领取状态只保存在本机，并随数据备份迁移；静态目录缓存不进入备份。

## 旧用户启动与存档安全

- 修复旧用户升级后进入选择题时，因智子资料尚未恢复而误显示领养提示、触发 React #310 错误的问题。
- 主界面继续快速打开；真正没有智子的新用户在资料检查结束后才看到领养入口。
- 资料恢复完成前，星途领奖、桌宠签到及切换智子不会提前写入旧存档；考试与智子页面同样等待恢复结果。
- 原有金币、智子、装备、典藏卡、衣橱、迷宫及试炼进度不迁移、不清空。已移除的课程与 AI 教练属于 v1.7.48，不在本次重复发布。
