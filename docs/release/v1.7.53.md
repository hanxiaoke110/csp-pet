# v1.7.53 发布说明

- 优秀码 EXC 恢复本地校验与兑换，不访问兑换 API；兼容现有教师端、Chrome 扩展的生成格式，三个奖级金额不变，按北京时间当天有效。

- 不改教师端、工坊/典藏卡/衣橱/课堂资料/题库在线目录，不新增美术资源。

## 边界与发布顺序

- 离线校验不是防作弊系统，不能防止修改系统时间、清空/回滚存档和逆向伪造。当前在线 EXC 接口保留供旧客户端使用；升级客户端后才切换为离线。
- Windows 原生实机验收沿用用户之前的跳过决定，不能把 CI 构建或包体校验解释为实机安装测试。
- 本地全量门禁→PR 合并→源码及 tag 同步→三平台 CI 构建/签名→安装包远程回读校验→自动升级指针回读→公告与飞书更新。
- 优先使用现有发布工作流。若自动上传无进展，保留成功 CI 产物按已有恢复流程补传，不重新编译或提前更新升级指针。
