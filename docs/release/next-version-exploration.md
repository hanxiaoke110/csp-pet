# 下一版本新增内容：智子试炼场迷雾探索

> 整理日期：2026-09-09
> 状态：已纳入 v1.7.46 发布范围；功能、资源、自动化测试与生产构建已完成。

## 玩家可见的新内容

- 8 个副本、40 个普通关卡全部新增首通迷宫；通关对应关卡后开放。
- 每关独立保存当前位置、步数、迷雾、题目、事件、路线选择、临时状态与结算状态，可中途退出后继续。
- 每张地图包含三个依次开放的主题区域、三道知识封印、玉简、岔路、宝箱、装备、商人、陷阱和出口事件。
- 支持方向键、WASD、点击相邻格和点击已探索道路自动寻路。
- 封印答错不会卡关，会显示解析、写入错题记录并继续探索。
- 地图金币与经验先暂存，到达出口后统一结算，避免重复发放。
- 副本页显示 1—5 关探索入口及“未开始 / 探索中 / 已完成”状态；战斗结算页可直接进入对应探索。

## 装备、道具与获取规则

- 新增武器、护甲、法器三个功能装备位，并保留 8 格探索行囊。
- 第一件武器、护甲或法器会自动装备，之后可在背包中自由切换。
- 40 关的装备与品级均为固定配置：不随机、不抽卡、没有隐藏概率。
- 同一固定装备再次获得时自动转为器魂碎片：普通 2、稀有 5、史诗 12、传说 25。
- 武器与护甲效果已接入答题战斗，包括开场护盾、答对护盾、有限次数增伤、三连追击、首次生命伤害减免和低生命恢复。
- 法器效果已接入普通迷宫，包括强化已走道路轮廓、预览最近普通事件、宝箱或商人方向。
- 净化玉符可在背包清除迷雾侵扰；当前没有适用减益时按钮禁用且不会误消耗。
- 战斗中常驻显示当前生效装备、已用/总触发次数，以及首次减伤、低生命恢复、护盾增伤的可用或暂停状态；触发时同步显示效果名称与数值。

## 说明与无障碍体验

- 探索帮助新增地图事件、装备、道具、器魂和固定掉落规则。
- 新增装备与道具图鉴，逐件展示品级、类别、实际效果、生效范围和固定来源关卡。
- 装备卡由悬停提示升级为可点击详情，触屏设备也能完整查看。
- 背包换装前展示当前同部位装备的名称与效果对比；每件物品明确显示失效条件和下一次重置时机。
- 本关帮助页直接显示本关的固定装备和品级。
- 禁用道具会解释不能使用的原因。

## 美术与界面

- 新增 8 套副本主题迷宫场景：玄武水庭、数术机关殿、灵码晶洞、万木根域、算法天阶、天算星台、真题古战场、五行龙魂境。
- 新增武器、护甲、法器、消耗品与地图事件图标；全部本地打包，无运行时外链依赖。
- 探索页面外框和迷宫底图会随当前副本切换，不再统一显示天机阁院落。
- 资源共 39 张 WebP，约 4.0 MiB；已覆盖当前全部功能入口，无缺失占位图。
- 新增图鉴双栏桌面布局和单栏窄屏布局，并支持减少动态效果偏好。

## 兼容性与质量

- 第一张迷宫继续使用旧地图 ID，已有玄武水庭探索进度不会丢失。
- 40 张地图均使用确定性生成；不同关卡存档互不覆盖。
- 已校验每张地图的三区、三道封印、事件和出口均可到达。
- 已通过 39 个测试文件、244 项自动化测试。
- TypeScript 检查和 Vite 生产构建通过。
- 已在内置浏览器检查第 40 关主题、固定掉落说明、装备图鉴和资源显示；无新增控制台错误。

## 本版本暂不包含

- 重复探索次数体系。
- 每周统一地图排名迷宫。
- 器魂兑换商店与装备强化。
- 付费抽卡或任何装备概率池。
