# v1.7.48 发布说明

> 发布日期：2026-09-21
> 发布节奏：本地门禁 → 版本提交 → GitHub/Gitee master → v1.7.48 标签 → 三平台 CI → Gitee/GitHub Release → update.json → 客户端公告 → 飞书更新文档 → 安装包 smoke。

## 学习区轻装升级

- 移除课程与 AI 教练入口，学习区保留选择题、CSP 真题、OJ 训练和学习资料。
- 旧的课程与 AI 地址会自动返回选择题，不出现空白页或失效入口。
- 移除 AI 服务配置、课程下载器和对应后端命令，新设备不再创建废弃数据表。
- 首次启动新版本会清理可重新下载的课程目录缓存，不删除学生学习记录。

## 成就与装扮迁移

- 已经达成或领取过的课程成就归入“绝版荣誉”，原金币和改名卡奖励继续有效。
- 未达成的旧课程成就不再占用成就总数，避免孩子面对无法继续完成的目标。
- 博学桂冠改为累计答对 100 道选择题，灵感铅笔改为完成 5 次每周任务，万卷星河改为超级挑战满分一次。
- 翠芯遗迹窗口皮肤改为自由练习累计答对 60 题。
- 所有迁移奖励均保留旧成就兜底；老玩家已经拥有的装扮与皮肤不会被收回。

## 数据与安装包兼容

- 金币、食物、智子、等级、好感度、装备、典藏卡、衣橱、昵称、头像、称号、迷宫与试炼进度保持不变。
- 历史课程完成记录仍保存在本地和备份中，只是不再作为学习入口展示。
- 生产构建排除旧课程目录、阶段、题库缓存与开发素材，继续控制三平台安装包体积。
- 线上旧课程文件暂时保留一个版本周期，确保尚未升级的旧客户端仍能正常使用。

## 验证结果

- Vitest：50 个测试文件、285 条测试全部通过。
- 题库完整链路：91 项检查全部通过，学生发布通道无争议题、坏题或缺失解析。
- 素材校验、主应用构建、迷宫构建与 Rust 后端检查通过。
- 旧成就、新成就、装扮继承、窗口皮肤和备份恢复均已覆盖专项回归。
