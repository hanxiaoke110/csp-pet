# v1.7.47 发布说明

> 发布日期：2026-09-20
> 发布节奏：本地门禁 → 静态内容发布 → 服务端与投票站核验 → 版本提交 → GitHub/Gitee master → v1.7.47 标签 → 三平台 CI → Gitee/GitHub Release → update.json → 飞书更新文档 → 安装包 smoke。

## 我的星途与星相衣橱

- 原“成就”入口升级为“我的”，整合今日星轨、成长手账、荣誉和星相衣橱。
- 首次建档可免费选择一个生肖头像和一个星座头像；24 个头像支持鼠标跟随与点击回应。
- 昵称首次修改免费，后续使用金币修改。
- 新增头像、头像框、背景、挂件、特效和称号搭配；购买项显示金币，成就项显示获取条件。
- 成长手账仅保存在本机并随备份迁移，不上传教师端或排行榜。

## 星辉典藏卡

- 侧边栏新增独立典藏卡入口，并使用班级码门禁。
- 首期开放阿斯特拉与芙宁娜两张传说典藏卡。
- 支持鼠标跟随幻光、翻面、自动赏卡、首次显影下载和离线欣赏。
- 拥有记录随备份迁移；换电脑后可按记录重新下载素材。
- 后续典藏卡和装扮可通过静态资源在线更新，无需重新发布客户端。

## 课程与在线内容

- 课程扩展至 P77，新增栈、递归、综合练习、真题演练、树与优先队列内容。
- C4 提高阶段正式开放，阶段毕业奖励与成就同步适配 P77。
- 课程、典藏卡、衣橱和智子工坊优先从 Cloudflare 静态资源加载，失败时回退 Gitee、本机缓存和安装包内容。
- 智子工坊素材增加大小与 SHA-256 校验，浏览和下载不再持续占用动态接口额度。

## 迷宫与备份修复

- 修复迷宫题目代码和配图缺失。
- 修复关闭地图事件后弹窗立即再次出现、无法继续移动。
- 迷宫结算明确区分发现金币与实际到账，并解释每日、每周奖励上限。
- 修复自动备份并发轮换导致新文件偶发找不到；恢复前会重新扫描真实备份目录。
- 备份覆盖典藏卡、个人资料、衣橱、成长手账、迷宫、试炼装备和奖励状态；可重新下载的素材缓存不进入备份。

## 平台与容量优化

- 新增免登录智子典藏投票站、一次一设备选票、匿名回执、每日快照与管理员导出。
- 试炼场只在奖励或进度真正变化时写入服务端，减少 D1 重复写入。
- 旧版学生存档保持兼容，不清空金币、智子、课程或迷宫进度。
