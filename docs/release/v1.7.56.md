# v1.7.56 · 错题随时练与省资源模式

- 在选择题页面可随时练习错题，支持 5 题、10 题或全部。月度奖励复盘仍按原有资格判断，同月奖励额度在重开后继续累计。
- 设置默认使用标准模式。手动启用省资源模式可简化动画和战斗画面，战斗判定时序保持一致。
- 设置可查看本机下载缓存大小，清理过期题库和下载临时文件。当前题库、上一版离线题库和存档受到保护。
- 智子配饰新增样式和搭配复制，改善脚下光环的遮挡关系，并修复部分试炼立绘加载失败。
- 典藏卡、配饰、课堂资料继续通过在线目录更新。本版内置课程目录包含 100 个课次槽位。

发布前本地校验通过 947 项应用测试、93 项题库检查和 9 项原生存储测试。正式安装包通过发布流水线构建及验证。
