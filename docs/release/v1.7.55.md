# v1.7.55 发布说明

日期：2026-10-29（Asia/Shanghai）。状态：正式安装包、自动更新、公告及飞书下载文档均已发布。

## 更新内容

- 装备工坊支持 10 个器魂碎片兑换 1 个自选属性晶石，可批量兑换，不花金币；原有碎片直接可用。
- 迷雾探索碎片计数、晶石及材料不足提示增加兑换或强化直达入口，明确材料用途。兑换保存失败不扣材料，同一确认不重复兑换。
- 修复试炼敌方被灼烧扣至 0 生命后仍开放下一回合的问题，拦截结束后的技能、延迟攻击和重复结算。
- 典藏卡查看界面适配窗口高度和滚动，翻面后文字、底部按钮可见；保留自动赏卡。
- 修复灵蛇和逐风马头像左右跟随反向，其他头像和在线新版本素材保持原映射。
- 许愿不再设同一愿望重复投票等待期，每次仍消耗一张许愿券，客户端配合服务端回执保护网络重试。原有票数保留。
- 统一试炼确认弹窗挂载到窗口顶层并限制高度，修复小窗口下确认按钮可能落到屏幕外的问题。

## 兼容与验证边界

不更改已有装备强化成本、掉落产量或最高 +5，不迁移或清空学生原有金币、碎片、晶石、智子及学习记录。教师使用入口不变。本轮无新增远程数据库迁移；许愿后端兼容调整已先行上线，不重复部署。

在线典藏卡保持现有线上目录，未将设计原稿或未跟踪素材纳入安装包。

沿用用户此前对 Windows 图形界面实机验收的豁免；发布仍需三平台 CI 构建、原生存储测试、安装包体积及更新签名验证。不得将浏览器模拟或 CI 构建表述为 Windows 原生实机操作验证。

发布前本地测试：113 个文件、769 项测试通过；题库全链路 93 项检查通过；素材检查零问题。
