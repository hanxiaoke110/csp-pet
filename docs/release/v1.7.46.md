# v1.7.46 发布说明

> 计划发布日期：2026-09-10
> 发布节奏：本地门禁 → 版本提交 → GitHub/Gitee master → v1.7.46 标签 → 三平台 CI → Gitee/GitHub Release → update.json → 飞书更新文档 → 安装包 smoke。

## 迷雾探索

- 8 个副本、40 个普通关卡各新增一张首通迷宫。
- 每关独立保存位置、步数、迷雾、题目、事件、路线、减益和结算状态。
- 每张地图包含三个主题区域、三道知识封印和完整探索事件。
- 支持键盘移动、点击移动和已探索道路自动寻路。
- 副本页与战斗结算页均可进入或继续对应迷宫。

## 装备与道具

- 新增武器、护甲、法器三个装备位和 8 格探索行囊。
- 武器与护甲实际参与战斗计算；法器实际影响普通迷宫提示与道路显示。
- 战斗内常驻显示触发次数、可用状态和暂停状态。
- 新增装备图鉴、固定来源、失效条件、重置时机和换装前效果对比。
- 每关装备与品级固定，无抽卡、无隐藏概率；重复装备自动转化为器魂。
- 净化玉符没有适用减益时不可使用且不会误消耗。

## 题库与练习

- GESP 选择题扩展到 1—8 级，新增 688 道 5—8 级高阶选择题及 69 张配套题图。
- 普通练习默认使用 1—4 级基础范围，5—8 级需主动选择。
- 题库发布快照、题图引用、题干代码显示和知识点映射同步更新。
- 发布渠道共包含 1698 道唯一已发布题目；争议题和损坏题继续隔离，不进入学生渠道。

## 战斗、智子与商城

- 五行克制改为完整闭环，并在战斗中显示克制关系和各属性被动特性。
- 八个副本 Boss 使用独立战斗形象。
- 第二赛季为账号提供一次免费智子属性调整机会。
- 商城食物支持输入数量、加减数量和最大可购数量。
- 智子精灵图优先加载 WebP 并保留 PNG 回退，减少安装包体积且兼容旧资源。

## 兼容性与构建

- 保留第一张迷宫旧存档 ID，已有玄武水庭进度不会丢失。
- 新增构建后资源裁剪与精灵图无损 WebP 转换，开发预览和未使用题库快照不进入安装包。
- 新增第三方许可说明并补充迷宫算法依赖许可。
- 当前发布门禁：245 项应用测试、91 项题库全链路检查、资源校验、主应用与独立试炼场构建全部通过。
