## 预留 P100

`public/course-data/learning-catalog.slots.json` 预留到 100。P78–P100 使用稳定课号及资料 ID，默认 hidden，不向学生展示空行，不包含伪造链接。预留项暂存 C4，仅为兼容现有四阶段结构，上线前要确认真实阶段。

生成器会保留在线新增、但 lessons.json 尚未加入的课程；不会因为重建只保留前 77 课。P100 并非硬上限，客户端当前可接收最多 500 条记录。

P70–P77 在在线目录中仍是制作中，只有实际飞书正文完成、阅读权限及链接回读验证通过后才标 ready。历史报告已有 P70、P71 飞书预建框架，后续先读取并检查是否可复用，不直接覆盖原文档或重复创建。

## 后续上线步骤

1. 老师确认内容，读取 P70/P71 旧框架，选择追加或新建，不覆盖已有素材。
2. 写入飞书，检查代码格式、过程表格、导航及学生只读权限。
3. 为 P70–P77 接入真实链接，设 ready；对 P78–P100 逐课补标题、阶段、说明和关键词后上架。
4. 递增目录版本，运行生成及校验，再部署 Cloudflare 并回读，检查客户端刷新结果。
5. 不要修改旧课程 ID 或学生进度，不需要因此再发布客户端。

重新检查草稿：`node scripts/check-course-cards-p70-p77.mjs`（需要 C++17 编译器，默认 clang++）。重新生成目录：`npm run learning-catalog:build`；上线校验：`npm run learning-catalog:validate`。
