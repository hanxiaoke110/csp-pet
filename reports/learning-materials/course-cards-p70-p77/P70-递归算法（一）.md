# P70｜递归算法（一）

阶段：C3 · 进阶。先会函数参数、返回值和条件判断，再读这张卡。

## 一、本课要掌握什么

- 给递归函数一句清楚的定义，例如 sum(n) 表示 1 到 n 的和。
- 找出口、写规模变小的调用、接住返回值。
- 分清递进时执行的语句和回归时执行的语句。

## 二、核心知识卡

递归不是“重复写同一段代码”，而是把当前问题交给一个规模更小的同类问题。每次调用都有自己的参数；外层调用会等待内层完成。

三问检查：最小情况直接得到什么答案？每次调用是否更接近出口？内层返回后，外层还要做什么？有出口不等于一定能终止，调用过程必须能到达出口。

### 递进与回归：以 sum(3) 为例

| 时刻 | 当前任务 | 发生什么 |
| --- | --- | --- |
| 递进 | sum(3) | 等 sum(2)，再加 3 |
| 递进 | sum(2) | 等 sum(1)，再加 2 |
| 出口 | sum(1) | 返回 1 |
| 回归 | sum(2) | 得到 1 + 2 = 3 |
| 回归 | sum(3) | 得到 3 + 3 = 6 |

调用前输出 n，会按 3、2、1 输出；先调用再输出 n，会按 1、2、3 输出。输出位置决定顺序，不是递归“随机执行”。

## 三、完整例题与代码

### 18206｜递归求累加和

输入正整数 n（1 ≤ n ≤ 100），输出 1 到 n 的和。输入 5，输出 15。

关系式 sum(n) = sum(n − 1) + n；出口 sum(1) = 1。下面用 sum(0) = 0 写成等价版本，合法输入结果相同；这是正确出口，不会造成结果偏差。

```cpp
#include <iostream>
using namespace std;
int sum(int n) {
    if (n == 0) return 0;
    return sum(n - 1) + n;
}
int main() {
    int n;
    cin >> n;
    cout << sum(n) << '\n';
    return 0;
}
```

每层只做一次加法，时间 O(n)、递归栈空间 O(n)。本题数据小；很大的 n 不适合这样层层递归。

### 18207｜最大公约数

输入两个正整数 a、b，输出最大公约数。输入 8 12，输出 4。过程是 (8,12) → (12,8) → (8,4) → (4,0)。最后返回 4。

```cpp
#include <iostream>
using namespace std;
int gcdRec(int a, int b) {
    if (b == 0) return a;
    return gcdRec(b, a % b);
}
int main() {
    int a, b;
    cin >> a >> b;
    cout << gcdRec(a, b) << '\n';
    return 0;
}
```

先判断 b 是否为 0，才能计算 a % b。这个版本也能处理 b = 0。复杂度 O(log(max(a,b)))。

## 四、易错点

- 只调用 sum(n − 1)，却没把它的返回值用于结果。
- 参数始终不变，无法接近出口；有出口也会无限调用。
- 阶乘用 int 存储会溢出；long long 也不是无限大，20! 可容纳，21! 已超出常用 64 位有符号范围。
- 把调用次数多与递归层数深混为一谈：时间和栈空间是两个问题。

## 五、先做再看：课后自测

1. sum(4) 的调用顺序和返回值分别是什么？
2. 让递归倒计时从 3 输出到 1，应把输出放在调用前还是调用后？
3. gcdRec(12,8) 的最终出口参数是什么？

答案：1. 调用 4→3→2→1→0，逐层返回 0、1、3、6、10。2. 调用前。3. (4,0)。
