# P72｜综合练习（一）

阶段：C4 · 提高。先复习枚举、队列、二分和栈。

## 一、本课要掌握什么

- 把“连续的一段”识别为窗口，把“范围内有多少”识别为二分计数。
- 用栈模拟只有一端可进出的轨道。
- 根据数据范围选方法，不把所有题都做成双重循环。

## 二、核心知识卡

| 题目线索 | 常用方法 | 必须检查 |
| --- | --- | --- |
| 连续区间、元素都为正、区间和有上限 | 滑动窗口 | 收缩能否让和下降 |
| 配对费用落在 [l,r] | 排序＋二分 | 重复值、端点、计数类型 |
| 固定进站序列、只能从轨道顶端出去 | 栈模拟 | 取 top 前必须非空 |

### 窗口走一遍

旅行团天数为 3、1、1、1、2、1，假期 5 天。右端走到第四个景点时和为 6，去掉左端的 3，得到 1、1、1；加入第五个景点 2 后，窗口和为 5、长度为 4。这是样例答案。

## 三、完整例题与代码

### 18803｜旅行团

按固定顺序游览，可任选起点，不能跳过中间景点。求总天数不超过 t 的最长连续段。1 ≤ n ≤ 100000，1 ≤ a_i ≤ 2000，1 ≤ t ≤ 10^8。

输入：第一行 n t，第二行 n 个天数。样例输入 `6 5` 和 `3 1 1 1 2 1`，输出 4。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    int n;
    long long t;
    cin >> n >> t;
    vector<int> a(n);
    for (int &x : a) cin >> x;
    int left = 0, ans = 0;
    long long sum = 0;
    for (int right = 0; right < n; ++right) {
        sum += a[right];
        while (sum > t) sum -= a[left++];
        ans = max(ans, right - left + 1);
    }
    cout << ans << '\n';
    return 0;
}
```

每个元素进入、离开窗口最多一次，时间 O(n)，本实现数组空间 O(n)。若单个景点大于 t，窗口会变空，答案仍正确。若允许负天数，不能直接套这个算法。

### 18804｜干饭人：二分边界

午餐价 a 固定时，晚餐价 b 必须位于 [l−a,r−a]。先排序晚餐数组，再用 upper_bound(r−a) − lower_bound(l−a) 得到数量，包含两端且保留重复价格对应的不同组合。

完整输入为 n m l r，之后分别输入 n 个午餐价、m 个晚餐价。样例：`4 3 6 13`，午餐 `5 3 12 6`，晚餐 `9 2 3`，输出 6。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    int n, m;
    long long l, r;
    cin >> n >> m >> l >> r;
    vector<long long> a(n), b(m);
    for (auto &x : a) cin >> x;
    for (auto &x : b) cin >> x;
    sort(b.begin(), b.end());
    long long ans = 0;
    for (long long x : a) {
        ans += upper_bound(b.begin(), b.end(), r - x)
             - lower_bound(b.begin(), b.end(), l - x);
    }
    cout << ans << '\n';
    return 0;
}
```

时间 O(m log m + n log m)，空间 O(n+m)。最多有 n×m 个组合，n、m 都为 100000 时达 10^10，必须用 long long 存答案。

## 四、易错点

- 窗口超限要用 while 收缩，不能只删一个元素。
- 古老车站的初始序列不一定是 1、2、3，必须按输入顺序入栈。
- 检查栈顶要写 `!st.empty() && st.top() == target`，不访问空栈。
- 不用答案 int 处理大规模组合计数。
