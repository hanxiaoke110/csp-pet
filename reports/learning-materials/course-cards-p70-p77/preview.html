P70｜递归算法（一）

阶段：C3 · 进阶。先会函数参数、返回值和条件判断，再读这张卡。

一、本课要掌握什么

  • 给递归函数一句清楚的定义，例如 sum(n) 表示 1 到 n 的和。
  • 找出口、写规模变小的调用、接住返回值。
  • 分清递进时执行的语句和回归时执行的语句。

二、核心知识卡

递归不是“重复写同一段代码”，而是把当前问题交给一个规模更小的同类问题。每次调用都有自己的参数；外层调用会等待内层完成。

三问检查：最小情况直接得到什么答案？每次调用是否更接近出口？内层返回后，外层还要做什么？有出口不等于一定能终止，调用过程必须能到达出口。

递进与回归：以 sum(3) 为例

时刻当前任务发生什么
递进sum(3)等 sum(2)，再加 3
递进sum(2)等 sum(1)，再加 2
出口sum(1)返回 1
回归sum(2)得到 1 + 2 = 3
回归sum(3)得到 3 + 3 = 6

调用前输出 n，会按 3、2、1 输出；先调用再输出 n，会按 1、2、3 输出。输出位置决定顺序，不是递归“随机执行”。

三、完整例题与代码

18206｜递归求累加和

输入正整数 n（1 ≤ n ≤ 100），输出 1 到 n 的和。输入 5，输出 15。

关系式 sum(n) = sum(n − 1) + n；出口 sum(1) = 1。下面用 sum(0) = 0 写成等价版本，合法输入结果相同；这是正确出口，不会造成结果偏差。

#include <iostream>
using namespace std;
int sum(int n) {
    if (n == 0) return 0;
    return sum(n - 1) + n;
}
int main() {
    int n;
    cin >> n;
    cout << sum(n) << '\n';
    return 0;
}

每层只做一次加法，时间 O(n)、递归栈空间 O(n)。本题数据小；很大的 n 不适合这样层层递归。

18207｜最大公约数

输入两个正整数 a、b，输出最大公约数。输入 8 12，输出 4。过程是 (8,12) → (12,8) → (8,4) → (4,0)。最后返回 4。

#include <iostream>
using namespace std;
int gcdRec(int a, int b) {
    if (b == 0) return a;
    return gcdRec(b, a % b);
}
int main() {
    int a, b;
    cin >> a >> b;
    cout << gcdRec(a, b) << '\n';
    return 0;
}

先判断 b 是否为 0，才能计算 a % b。这个版本也能处理 b = 0。复杂度 O(log(max(a,b)))。

四、易错点

  • 只调用 sum(n − 1)，却没把它的返回值用于结果。
  • 参数始终不变，无法接近出口；有出口也会无限调用。
  • 阶乘用 int 存储会溢出；long long 也不是无限大，20! 可容纳，21! 已超出常用 64 位有符号范围。
  • 把调用次数多与递归层数深混为一谈：时间和栈空间是两个问题。

五、先做再看：课后自测

1. sum(4) 的调用顺序和返回值分别是什么？

2. 让递归倒计时从 3 输出到 1，应把输出放在调用前还是调用后？

3. gcdRec(12,8) 的最终出口参数是什么？

答案：1. 调用 4→3→2→1→0，逐层返回 0、1、3、6、10。2. 调用前。3. (4,0)。

P71｜递归算法（二）

阶段：C3 · 进阶。先复习 P70 的递归含义、出口和返回值。

一、本课要掌握什么

  • 用“最后一步”把方案计数拆成互不重叠的情况。
  • 识别重复计算，用记忆化保存状态答案。
  • 枚举分解时约定非递减顺序，避免把换序当新方案。

二、核心知识卡

楼梯每步走 1 或 2 级。f(n) 表示到达第 n 级的方案数。最后一步来自 n−1 或 n−2，这两种情况不重叠，因此 f(n)=f(n−1)+f(n−2)。

n12345
f(n)12358

普通递归里 f(5) 调 f(4)、f(3)，f(4) 又调 f(3)、f(2)：同一个 f(3) 被算了两遍。记忆化像答案本：第一次计算并记下，以后直接读取。

三、完整例题与代码

18350｜再爬一次（升级版）

输入 n（1 ≤ n ≤ 50），输出走法数。输入 3，输出 3；输入 50，输出 20365011074，需要 long long。

#include <iostream>
using namespace std;
long long memo[51] = {};
long long ways(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    if (memo[n] != 0) return memo[n];
    memo[n] = ways(n - 1) + ways(n - 2);
    return memo[n];
}
int main() {
    int n;
    cin >> n;
    cout << ways(n) << '\n';
    return 0;
}

本题所有合法状态答案都大于 0，所以 0 可以表示“未计算”。若别的题答案可能为 0，应另用 visited 数组或不会与答案冲突的标记。记忆化后时间、数组和递归栈均为 O(n)。

18352｜数的分解

把正整数 n 写成若干个大于 1 的整数的乘积，因数按非递减顺序排列；单独的 n 本身也算一种。这里以 2 ≤ n ≤ 1000 为演示范围。输入 12，输出 4：12、2×6、3×4、2×2×3。

f(low,rest) 表示剩余乘积 rest、下一因数至少为 low 时的方案数。初始的 1 种方案是“直接选 rest”；继续拆时只枚举 low ≤ d ≤ rest/d 且 d 整除 rest。

#include <iostream>
using namespace std;
long long countWays(int low, int rest) {
    long long ans = 1;
    for (int d = low; d <= rest / d; ++d) {
        if (rest % d == 0) ans += countWays(d, rest / d);
    }
    return ans;
}
int main() {
    int n;
    cin >> n;
    cout << countWays(2, n) << '\n';
    return 0;
}

递归后 low=d，后续因数不能比 d 小，因此 2×6 与 6×2 不会重复统计。本例是搜索枚举，不承诺像爬楼梯那样 O(n)；范围扩大后应重新评估时间。

四、易错点

  • f(n−1)+f(n−2) 适用于每步 1 或 2 级；增加 3 级步长后关系式和出口都要改。
  • n=50 的结果超过 int；只改数组类型却不改函数返回类型仍会溢出。
  • 分解时忘记最小因数限制，会重复计算排列。
  • 记忆化键必须覆盖所有影响结果的参数；f(low,rest) 不能只按 rest 缓存。

五、先做再看：课后自测

1. f(4) 有几种走法？2. f(3) 已缓存，下一次调用还会递归算子问题吗？3. 8 有哪些乘积分解？

答案：1. 5。2. 不会，直接返回缓存。3. 8、2×4、2×2×2，共 3 种。

18803｜旅行团

按固定顺序游览，可任选起点，不能跳过中间景点。求总天数不超过 t 的最长连续段。1 ≤ n ≤ 100000，1 ≤ a_i ≤ 2000，1 ≤ t ≤ 10^8。

输入：第一行 n t，第二行 n 个天数。样例输入 6 5 和 3 1 1 1 2 1，输出 4。

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    int n;
    long long t;
    cin >> n >> t;
    vector<int> a(n);
    for (int &x : a) cin >> x;
    int left = 0, ans = 0;
    long long sum = 0;
    for (int right = 0; right < n; ++right) {
        sum += a[right];
        while (sum > t) sum -= a[left++];
        ans = max(ans, right - left + 1);
    }
    cout << ans << '\n';
    return 0;
}

每个元素进入、离开窗口最多一次，时间 O(n)，本实现数组空间 O(n)。若单个景点大于 t，窗口会变空，答案仍正确。若允许负天数，不能直接套这个算法。

18804｜干饭人：二分边界

午餐价 a 固定时，晚餐价 b 必须位于 [l−a,r−a]。先排序晚餐数组，再用 upper_bound(r−a) − lower_bound(l−a) 得到数量，包含两端且保留重复价格对应的不同组合。

完整输入为 n m l r，之后分别输入 n 个午餐价、m 个晚餐价。样例：4 3 6 13，午餐 5 3 12 6，晚餐 9 2 3，输出 6。

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    int n, m;
    long long l, r;
    cin >> n >> m >> l >> r;
    vector<long long> a(n), b(m);
    for (auto &x : a) cin >> x;
    for (auto &x : b) cin >> x;
    sort(b.begin(), b.end());
    long long ans = 0;
    for (long long x : a) {
        ans += upper_bound(b.begin(), b.end(), r - x)
             - lower_bound(b.begin(), b.end(), l - x);
    }
    cout << ans << '\n';
    return 0;
}

时间 O(m log m + n log m)，空间 O(n+m)。最多有 n×m 个组合，n、m 都为 100000 时达 10^10，必须用 long long 存答案。

四、易错点

  • 窗口超限要用 while 收缩，不能只删一个元素。
  • 古老车站的初始序列不一定是 1、2、3，必须按输入顺序入栈。
  • 检查栈顶要写 !st.empty() && st.top() == target，不访问空栈。
  • 不用答案 int 处理大规模组合计数。

五、先做再看：课后自测

1. 天数全是 6，t=5，答案是多少？2. 晚餐 [2,2,3] 中 [2,2] 有几个元素？3. 窗口和超限一次，是否只收缩一次就够？

答案：1. 0。2. 2。3. 不一定，要收缩到合法。

P73｜综合练习（二）

阶段：C4 · 提高。先复习递归、整除、取模与整数范围。

一、本课要掌握什么

  • 用递归描述汉诺塔的三步，而不是试图记住所有移动。
  • 用平方分解指数，以快速幂替代逐次相乘。
  • 分清“移动次数少”和“输出移动过程仍然很长”。

二、核心知识卡

汉诺塔：从 A 经 B 移到 C

1. 把上面 n−1 个盘从 A 经 C 移到 B。

2. 把第 n 个大盘从 A 移到 C。

3. 把 B 上 n−1 个盘经 A 移到 C。

T(n)=2T(n−1)+1，T(1)=1，所以 T(n)=2^n−1。输出完整过程时本身就有 2^n−1 行，不能因为用了递归就说时间 O(n)。

指数 b计算拆分
偶数 2ka^b=(a^k)^2
奇数 2k+1a^b=(a^k)^2×a

每次 b 减半，快速幂循环次数 O(log b)。取模可在每次乘法后做，但乘法在取模前仍可能溢出，必须选合适类型。

19736｜幂的最后四位

输入 a b，1 ≤ a ≤ 100000，1 ≤ b ≤ 10^9。输出 a^b 模 10000 的整数余数；本课堂题的样例 2 9 输出 512，不强制补成 0512。

#include <iostream>
using namespace std;
int main() {
    long long a, b;
    cin >> a >> b;
    a %= 10000;
    long long ans = 1;
    while (b > 0) {
        if (b % 2 == 1) ans = ans * a % 10000;
        a = a * a % 10000;
        b /= 2;
    }
    cout << ans << '\n';
    return 0;
}

由于每个乘数已在 [0,9999]，long long 乘法安全。不要用浮点 pow 后再取模，较大指数会丢精度或溢出。样例 12 5 输出 8832。

19734｜汉诺塔过程

输入 n（1 ≤ n ≤ 10），输出最少移动过程。n=2 时：1 从 A 到 B；2 从 A 到 C；1 从 B 到 C，各占一行。

#include <iostream>
using namespace std;
void hanoi(int n, char from, char mid, char to) {
    if (n == 1) {
        cout << "1 从 " << from << " 到 " << to << '\n';
        return;
    }
    hanoi(n - 1, from, to, mid);
    cout << n << " 从 " << from << " 到 " << to << '\n';
    hanoi(n - 1, mid, from, to);
}
int main() {
    int n;
    cin >> n;
    hanoi(n, 'A', 'B', 'C');
    return 0;
}

时间 O(2^n)，递归栈 O(n)。参数名始终表示当前子任务中的出发柱、辅助柱、目标柱，不是永远指固定的 A、B、C。

四、易错点

  • 汉诺塔第二次递归参数照抄第一次，导致方向错。
  • 快速幂每次把原始 a 再乘进去，忘记平方后的 a 已表示当前权值。
  • %10000 写在 int 溢出之后，无法修复此前的溢出。
  • 忘记 a^0=1；上面程序也支持 b=0，可用作边界自测。

答案：1. 7。2. 8、4、1，即 13=8+4+1。3. 不补零，输出 512。

19960｜拼数

输入一个仅含小写字母和数字的字符串，长度 ≤10^6，保证至少一个非零数字。每个数字字符最多使用一次，任意重排，求最大的正整数。

输入 290es1q0，输出 92100。按 9 到 0 输出各数字，不能转成 int 再输出，也不能丢掉尾部的 0。

#include <iostream>
#include <string>
using namespace std;
int main() {
    string s;
    cin >> s;
    int cnt[10] = {};
    for (char c : s) {
        if (c >= '0' && c <= '9') ++cnt[c - '0'];
    }
    for (int d = 9; d >= 0; --d) {
        for (int k = 0; k < cnt[d]; ++k) cout << d;
    }
    cout << '\n';
    return 0;
}

交换论证：若高位数字比后面的数字小，交换后数更大；因此最大排列为非递增排列。时间 O(|s|)，输入字符串空间 O(|s|)，计数额外空间 O(1)。

19961｜导弹拦截：最少系统数

课堂输入为 n，随后 n 个高度（n ≤100000）；只输出拦截全部导弹需要的最少系统数。本卡代码不是“输出最长可拦截序列”的另一问。

#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    int n;
    cin >> n;
    vector<int> tail;
    for (int i = 0; i < n; ++i) {
        int h;
        cin >> h;
        auto it = lower_bound(tail.begin(), tail.end(), h);
        if (it == tail.end()) tail.push_back(h);
        else *it = h;
    }
    cout << tail.size() << '\n';
    return 0;
}

选可用末高度中最小的一个，能把更高的系统留给以后。替换 first ≥h 的位置不会破坏有序性。时间 O(n log n)，空间 O(n)。

四、易错点

  • 拼数用整数保存，长度很大时溢出；应直接输出字符或计数。
  • 拦截题混淆非递增和严格递减；相等高度允许接入。
  • 公路题只卖整数升，加油量需向上取整；不能把每段各自向上取整后忽略余油。
  • 本卡的公路策略依赖油箱无限大；有限容量题不能直接套用。

阶段：C4 · 提高。本卡按课堂题板改编格式练习；先复习结构体、模拟、二进制和递归。

一、本课要掌握什么

  • 把规则转成状态：面额、获得时间、是否使用。
  • 严格按“最早的可用票”选择，不能选最大面额或直接取第一张票。
  • 用二进制分解整数，并递归格式化指数。

二、核心知识卡

公交优惠票同时满足：未使用、时间差 ≤45 分钟、票面额 ≥公交票价。多个符合时取获得最早的那张。

记录处理累计费用

地铁 20 元，时刻 16支付 20，记一张票25
地铁 7 元，时刻 23支付 7，记一张票32
公交 18 元，时刻 31消耗时刻 16 的票32
公交 4 元，时刻 38消耗时刻 1 的票32

优惠票仅用于公交，坐地铁仍需支付；用过的票不能再次使用。

三、完整例题与代码

18895｜公交换乘

输入 n，之后每行 op price time；op=0 是地铁，op=1 是公交。保证记录时间严格递增且每分钟最多一条。输出总费用。

#include <iostream>
#include <vector>
using namespace std;
struct Ticket { int price, time; bool used; };
int main() {
    int n;
    cin >> n;
    vector<Ticket> tickets;
    int first = 0;
    long long cost = 0;
    for (int i = 0; i < n; ++i) {
        int op, price, time;
        cin >> op >> price >> time;
        while (first < static_cast<int>(tickets.size())
               && time - tickets[first].time > 45) ++first;
        if (op == 0) {
            cost += price;
            tickets.push_back({price, time, false});
        } else {
            bool found = false;
            for (int j = first; j < static_cast<int>(tickets.size()); ++j) {
                if (!tickets[j].used && tickets[j].price >= price) {
                    tickets[j].used = true;
                    found = true;
                    break;
                }
            }
            if (!found) cost += price;
        }
    }
    cout << cost << '\n';
    return 0;
}

时间差 >45 才过期；恰好 45 可用。严格递增的整数分钟保证每次公交前有效时间段中最多有 45 张地铁票，所以扫描时间 O(45n)，存票空间 O(n)。若允许同一分钟多条记录，这个时间界限不再成立，要重新选算法。

19098｜幂次方

输入 1 ≤ n ≤20000，输出题目约定的 0、2 表示法：2^0 写成 2(0)，2^1 写成 2，其他指数递归表示，无空格。

137=2^7+2^3+2^0。7=2^2+2+2^0，因此输出 2(2(2)+2+2(0))+2(2+2(0))+2(0)。

#include <iostream>
using namespace std;
void show(int n) {
    bool first = true;
    for (int k = 14; k >= 0; --k) {
        if ((n & (1 << k)) == 0) continue;
        if (!first) cout << '+';
        first = false;
        if (k == 0) cout << "2(0)";
        else if (k == 1) cout << '2';
        else {
            cout << "2(";
            show(k);
            cout << ')';
        }
    }
}
int main() {
    int n;
    cin >> n;
    show(n);
    cout << '\n';
    return 0;
}

20000 小于 2^15，所以扫描位 14 到 0 足够。递归处理的是指数 k，规模迅速减小；时间取决于生成的表达式和各调用扫描位数，不能把它说成只调用一次 O(log n)。

四、易错点

  • 公交按 <45 判断，误排除时间差等于 45 的票。
  • 看到最早票面额不足就停止；应该继续找后面的可用票。
  • 过期票与使用过的票是两个状态，不能混用。
  • 幂次方的 2^1 输出成 2(1)，不符合本题约定；加号不能放首尾。

五、先做再看：课后自测

1. 时刻 1 的票在时刻 46 能否使用？2. 票价恰好相等能否用？3. 10 的表达式是什么？

答案：1. 能，差 45。2. 能。3. 2(2+2(0))+2。

P76｜树（一）

阶段：C4 · 提高。先复习数组、函数、递归和队列。

一、本课要掌握什么

  • 分清根、父亲、孩子、兄弟、叶子和子树。
  • 本课堂约定根的深度为 1，树深度是结点深度的最大值。
  • 二叉树最多有两个孩子；“最多两个”不等于“必须两个”。

二、核心知识卡

        1
       / \
      2   3
     / \
    4   5

根为 1；2 的父亲为 1；4、5 是兄弟；叶子为 3、4、5。结点 4 深度为 3，本图树深度为 3。另一些题定义根深度为 0，做题时必须看题意。

遍历访问顺序上图结果
前序根、左、右1 2 4 5 3
中序左、根、右4 2 5 1 3
后序左、右、根4 5 2 3 1

“根”不是只指整棵树的 1，而是每次递归处理的当前子树根。

21256｜找树根和深度

输入 n，随后 n−1 行 x y 表示 y 是 x 的孩子，保证为合法有根树，编号 1 到 n，n ≤10000。输出两行：根编号、深度。n=1 时根为 1，深度为 1。

#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;
int main() {
    int n;
    cin >> n;
    vector<vector<int>> children(n + 1);
    vector<int> parent(n + 1, 0), depth(n + 1, 0);
    for (int i = 1; i < n; ++i) {
        int x, y;
        cin >> x >> y;
        children[x].push_back(y);
        parent[y] = x;
    }
    int root = 1;
    while (parent[root] != 0) ++root;
    queue<int> q;
    q.push(root);
    depth[root] = 1;
    int answer = 1;
    while (!q.empty()) {
        int x = q.front(); q.pop();
        for (int y : children[x]) {
            depth[y] = depth[x] + 1;
            answer = max(answer, depth[y]);
            q.push(y);
        }
    }
    cout << root << '\n' << answer << '\n';
    return 0;
}

每条边处理一次，时间、空间均为 O(n)。这里用队列按层访问，避免从每个结点重复沿父亲链计算导致链状树 O(n²)，也避免很深的递归栈。

21258｜中序遍历

输入 n，随后 n 行 x l r 表示 x 的左右孩子，0 表示缺少孩子。保证合法二叉树，结点编号为 1 到 n，1 ≤ n ≤1000；根不一定是 1，输入行也不一定按编号顺序。

#include <iostream>
#include <vector>
using namespace std;
vector<int> leftChild, rightChild;
bool first = true;
void inorder(int x) {
    if (x == 0) return;
    inorder(leftChild[x]);
    if (!first) cout << ' ';
    first = false;
    cout << x;
    inorder(rightChild[x]);
}
int main() {
    int n;
    cin >> n;
    leftChild.assign(n + 1, 0);
    rightChild.assign(n + 1, 0);
    vector<int> parent(n + 1, 0);
    for (int i = 0; i < n; ++i) {
        int x, l, r;
        cin >> x >> l >> r;
        leftChild[x] = l; rightChild[x] = r;
        if (l) parent[l] = x;
        if (r) parent[r] = x;
    }
    int root = 1;
    while (parent[root] != 0) ++root;
    inorder(root);
    cout << '\n';
    return 0;
}

每个结点访问一次，时间 O(n)，数组 O(n)，递归栈 O(h)，h 为树高。若题目允许极深的树，可用显式栈改写遍历。

四、易错点

  • 默认第一个输入结点就是根。正确做法是找没有父亲的结点。
  • 0 是空孩子标记，不是实际结点；递归必须先判断 0。
  • 中序遍历只是访问顺序，不保证结果有序；只有二叉搜索树在相应键值规则下才有此性质。
  • 求子树人数时必须计入自己：size(x)=1+size(left)+size(right)。

五、先做再看：课后自测

1. 上图 2 的子树有几人？2. 只有根的一棵树，按本课约定深度为多少？3. 中序访问 2 前要先访问谁？

答案：1. 3。2. 1。3. 左子树中的 4。

P77｜特殊二叉树与优先队列

阶段：C4 · 提高。先复习 P76 的树、贪心和 STL 容器。

一、本课要掌握什么

  • 完全二叉树：除最后一层外都填满，最后一层从左到右连续排列。
  • 堆：有完全二叉树的形状，还满足父子之间的大小关系。
  • priority_queue：快速取得最高优先级元素，而不是按到达顺序排队。

二、核心知识卡

容器谁先出来本课场景
queue最先加入的普通排队
默认 priority_queue当前最大值按紧急值分诊
小根 priority_queue当前最小值合并最轻的两堆

堆顶最值不代表整个堆已经排序。大根堆保证父结点 ≥孩子，小根堆保证父结点 ≤孩子；与二叉搜索树“左小右大”不同。

合并过程：1、2、9

轮次选择两堆新堆累计体力
11、233
23、91215

若先合 2、9，体力为 11+12=23。较小权值先合并，让较重的果堆被重复计费的次数尽量少。这对应哈夫曼构造的贪心选择，不是任意“挑两个”都最优。

三、完整例题与代码

急诊分诊（课堂自编题）

输入操作数 m，之后每行 1 x 加入紧急值 x，或 2 输出并移除当前最大紧急值。题目保证执行 2 时非空。样例：加入 3、加入 8、就诊、加入 5、就诊、就诊，分别输出 8、5、3。

#include <iostream>
#include <queue>
using namespace std;
int main() {
    int m;
    cin >> m;
    priority_queue<int> q;
    for (int i = 0; i < m; ++i) {
        int op;
        cin >> op;
        if (op == 1) {
            int x; cin >> x;
            q.push(x);
        } else {
            cout << q.top() << '\n';
            q.pop();
        }
    }
    return 0;
}

push、pop 为 O(log m)，top 为 O(1)。相同紧急值都保留；本题只输出值，不保证同值病人的先后，若需要先到先服务应额外记录到达序号。

合并果子（课堂题）

输入 n，随后 n 个正整数表示果堆重量。每次合并两堆花费它们重量之和，求全部合为一堆的最少体力。n ≤10000，总重量 ≤2×10^8。输入 3 和 1 2 9，输出 15。

#include <iostream>
#include <queue>
#include <vector>
#include <functional>
using namespace std;
int main() {
    int n;
    cin >> n;
    priority_queue<long long, vector<long long>, greater<long long>> q;
    for (int i = 0; i < n; ++i) {
        long long x; cin >> x;
        q.push(x);
    }
    long long ans = 0;
    while (q.size() > 1) {
        long long a = q.top(); q.pop();
        long long b = q.top(); q.pop();
        ans += a + b;
        q.push(a + b);
    }
    cout << ans << '\n';
    return 0;
}

新堆必须放回继续参与选择。总共 n−1 次合并，时间 O(n log n)，空间 O(n)。只有一堆时不需要合并，答案为 0。

四、易错点

  • 忘记 greater，用大根堆合并最大两堆，无法得到最小体力。
  • pop 不返回元素；先取 top，再 pop，且不能对空堆这样做。
  • 只加最终总重量，忘记每轮合并都消耗体力。
  • 权值总和与累计合并费用不同，累计值可能更大，使用 long long。
  • 带权路径长度 WPL 是所有叶子的“权值×从根到该叶子的边数”之和。合并费用等于对应哈夫曼树的 WPL。只有一个叶子时经过 0 条边，WPL 和合并费用均为 0；不要混淆边数路径长与上一课“根深度为 1”。

五、先做再看：课后自测

1. 仅一堆重 7，答案是多少？2. 四堆都重 1，最少体力是多少？3. 默认 priority_queue 的 top 是最小值吗？

答案：1. 0。2. 2+2+4=8。3. 不是，是最大值。
