# P73｜综合练习（二）

阶段：C4 · 提高。先复习递归、整除、取模与整数范围。

## 一、本课要掌握什么

- 用递归描述汉诺塔的三步，而不是试图记住所有移动。
- 用平方分解指数，以快速幂替代逐次相乘。
- 分清“移动次数少”和“输出移动过程仍然很长”。

## 二、核心知识卡

### 汉诺塔：从 A 经 B 移到 C

1. 把上面 n−1 个盘从 A 经 C 移到 B。
2. 把第 n 个大盘从 A 移到 C。
3. 把 B 上 n−1 个盘经 A 移到 C。

T(n)=2T(n−1)+1，T(1)=1，所以 T(n)=2^n−1。输出完整过程时本身就有 2^n−1 行，不能因为用了递归就说时间 O(n)。

| 指数 b | 计算拆分 |
| --- | --- |
| 偶数 2k | a^b=(a^k)^2 |
| 奇数 2k+1 | a^b=(a^k)^2×a |

每次 b 减半，快速幂循环次数 O(log b)。取模可在每次乘法后做，但乘法在取模前仍可能溢出，必须选合适类型。

## 三、完整例题与代码

### 19736｜幂的最后四位

输入 a b，1 ≤ a ≤ 100000，1 ≤ b ≤ 10^9。输出 a^b 模 10000 的整数余数；本课堂题的样例 2 9 输出 512，不强制补成 0512。

```cpp
#include <iostream>
using namespace std;
int main() {
    long long a, b;
    cin >> a >> b;
    a %= 10000;
    long long ans = 1;
    while (b > 0) {
        if (b % 2 == 1) ans = ans * a % 10000;
        a = a * a % 10000;
        b /= 2;
    }
    cout << ans << '\n';
    return 0;
}
```

由于每个乘数已在 [0,9999]，long long 乘法安全。不要用浮点 pow 后再取模，较大指数会丢精度或溢出。样例 12 5 输出 8832。

### 19734｜汉诺塔过程

输入 n（1 ≤ n ≤ 10），输出最少移动过程。n=2 时：1 从 A 到 B；2 从 A 到 C；1 从 B 到 C，各占一行。

```cpp
#include <iostream>
using namespace std;
void hanoi(int n, char from, char mid, char to) {
    if (n == 1) {
        cout << "1 从 " << from << " 到 " << to << '\n';
        return;
    }
    hanoi(n - 1, from, to, mid);
    cout << n << " 从 " << from << " 到 " << to << '\n';
    hanoi(n - 1, mid, from, to);
}
int main() {
    int n;
    cin >> n;
    hanoi(n, 'A', 'B', 'C');
    return 0;
}
```

时间 O(2^n)，递归栈 O(n)。参数名始终表示当前子任务中的出发柱、辅助柱、目标柱，不是永远指固定的 A、B、C。

## 四、易错点

- 汉诺塔第二次递归参数照抄第一次，导致方向错。
- 快速幂每次把原始 a 再乘进去，忘记平方后的 a 已表示当前权值。
- `%10000` 写在 int 溢出之后，无法修复此前的溢出。
- 忘记 a^0=1；上面程序也支持 b=0，可用作边界自测。

## 五、先做再看：课后自测

1. 3 个盘最少几次？2. b=13 的二进制 1101 代表选择哪些指数权值？3. 本题 2^9 输出是否补零？

答案：1. 7。2. 8、4、1，即 13=8+4+1。3. 不补零，输出 512。
