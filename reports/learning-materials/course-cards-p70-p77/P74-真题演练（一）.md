# P74｜真题演练（一）

阶段：C4 · 提高。本卡按课堂题板的改编题意讲解；不要把改编后的输入、输出当成原比赛题目的完整格式。

## 一、本课要掌握什么

- 从字符串中抽取数字，保持字符串答案，避免超长整数溢出。
- 把贪心选择说清楚：选哪个、为什么不妨碍后续。
- 二分必须建立在有序状态上，不能对未排序数组直接查找。

## 二、核心知识卡

| 题型 | 核心选择 | 保存的状态 |
| --- | --- | --- |
| 拼数 | 较大的数字放在高位 | 各数字出现次数 |
| 导弹拦截系统数 | 选可拦截且末高度最小的系统 | 有序的各系统末高度 |
| 公路加油 | 已到达站点中的最低油价 | 最低价、剩余可行驶距离 |

### 导弹拦截：389、207、158、300、155、159

| 新高度 | 有序末高度（处理后） | 解释 |
| --- | --- | --- |
| 389 | 389 | 开新系统 |
| 207 | 207 | 接入已有系统 |
| 158 | 158 | 接入已有系统 |
| 300 | 158、300 | 158 无法接更高的导弹，开新系统 |
| 155 | 155、300 | 接到第一个末高度 ≥155 的系统 |
| 159 | 155、159 | 接到第一个末高度 ≥159 的系统 |

最终要 2 套系统。相等高度也能接，所以查找使用 lower_bound，不是 upper_bound。

## 三、完整例题与代码

### 19960｜拼数

输入一个仅含小写字母和数字的字符串，长度 ≤10^6，保证至少一个非零数字。每个数字字符最多使用一次，任意重排，求最大的正整数。

输入 `290es1q0`，输出 `92100`。按 9 到 0 输出各数字，不能转成 int 再输出，也不能丢掉尾部的 0。

```cpp
#include <iostream>
#include <string>
using namespace std;
int main() {
    string s;
    cin >> s;
    int cnt[10] = {};
    for (char c : s) {
        if (c >= '0' && c <= '9') ++cnt[c - '0'];
    }
    for (int d = 9; d >= 0; --d) {
        for (int k = 0; k < cnt[d]; ++k) cout << d;
    }
    cout << '\n';
    return 0;
}
```

交换论证：若高位数字比后面的数字小，交换后数更大；因此最大排列为非递增排列。时间 O(|s|)，输入字符串空间 O(|s|)，计数额外空间 O(1)。

### 19961｜导弹拦截：最少系统数

课堂输入为 n，随后 n 个高度（n ≤100000）；只输出拦截全部导弹需要的最少系统数。本卡代码不是“输出最长可拦截序列”的另一问。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;
int main() {
    int n;
    cin >> n;
    vector<int> tail;
    for (int i = 0; i < n; ++i) {
        int h;
        cin >> h;
        auto it = lower_bound(tail.begin(), tail.end(), h);
        if (it == tail.end()) tail.push_back(h);
        else *it = h;
    }
    cout << tail.size() << '\n';
    return 0;
}
```

选可用末高度中最小的一个，能把更高的系统留给以后。替换 first ≥h 的位置不会破坏有序性。时间 O(n log n)，空间 O(n)。

## 四、易错点

- 拼数用整数保存，长度很大时溢出；应直接输出字符或计数。
- 拦截题混淆非递增和严格递减；相等高度允许接入。
- 公路题只卖整数升，加油量需向上取整；不能把每段各自向上取整后忽略余油。
- 本卡的公路策略依赖油箱无限大；有限容量题不能直接套用。
