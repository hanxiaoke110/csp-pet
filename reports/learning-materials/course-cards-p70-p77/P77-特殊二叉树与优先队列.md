# P77｜特殊二叉树与优先队列

阶段：C4 · 提高。先复习 P76 的树、贪心和 STL 容器。

## 一、本课要掌握什么

- 完全二叉树：除最后一层外都填满，最后一层从左到右连续排列。
- 堆：有完全二叉树的形状，还满足父子之间的大小关系。
- priority_queue：快速取得最高优先级元素，而不是按到达顺序排队。

## 二、核心知识卡

| 容器 | 谁先出来 | 本课场景 |
| --- | --- | --- |
| queue | 最先加入的 | 普通排队 |
| 默认 priority_queue | 当前最大值 | 按紧急值分诊 |
| 小根 priority_queue | 当前最小值 | 合并最轻的两堆 |

堆顶最值不代表整个堆已经排序。大根堆保证父结点 ≥孩子，小根堆保证父结点 ≤孩子；与二叉搜索树“左小右大”不同。

### 合并过程：1、2、9

| 轮次 | 选择两堆 | 新堆 | 累计体力 |
| --- | --- | --- | --- |
| 1 | 1、2 | 3 | 3 |
| 2 | 3、9 | 12 | 15 |

若先合 2、9，体力为 11+12=23。较小权值先合并，让较重的果堆被重复计费的次数尽量少。这对应哈夫曼构造的贪心选择，不是任意“挑两个”都最优。

## 三、完整例题与代码

### 急诊分诊（课堂自编题）

输入操作数 m，之后每行 `1 x` 加入紧急值 x，或 `2` 输出并移除当前最大紧急值。题目保证执行 2 时非空。样例：加入 3、加入 8、就诊、加入 5、就诊、就诊，分别输出 8、5、3。

```cpp
#include <iostream>
#include <queue>
using namespace std;
int main() {
    int m;
    cin >> m;
    priority_queue<int> q;
    for (int i = 0; i < m; ++i) {
        int op;
        cin >> op;
        if (op == 1) {
            int x; cin >> x;
            q.push(x);
        } else {
            cout << q.top() << '\n';
            q.pop();
        }
    }
    return 0;
}
```

push、pop 为 O(log m)，top 为 O(1)。相同紧急值都保留；本题只输出值，不保证同值病人的先后，若需要先到先服务应额外记录到达序号。

### 合并果子（课堂题）

输入 n，随后 n 个正整数表示果堆重量。每次合并两堆花费它们重量之和，求全部合为一堆的最少体力。n ≤10000，总重量 ≤2×10^8。输入 `3` 和 `1 2 9`，输出 15。

```cpp
#include <iostream>
#include <queue>
#include <vector>
#include <functional>
using namespace std;
int main() {
    int n;
    cin >> n;
    priority_queue<long long, vector<long long>, greater<long long>> q;
    for (int i = 0; i < n; ++i) {
        long long x; cin >> x;
        q.push(x);
    }
    long long ans = 0;
    while (q.size() > 1) {
        long long a = q.top(); q.pop();
        long long b = q.top(); q.pop();
        ans += a + b;
        q.push(a + b);
    }
    cout << ans << '\n';
    return 0;
}
```

新堆必须放回继续参与选择。总共 n−1 次合并，时间 O(n log n)，空间 O(n)。只有一堆时不需要合并，答案为 0。

## 四、易错点

- 忘记 greater，用大根堆合并最大两堆，无法得到最小体力。
- pop 不返回元素；先取 top，再 pop，且不能对空堆这样做。
- 只加最终总重量，忘记每轮合并都消耗体力。
- 权值总和与累计合并费用不同，累计值可能更大，使用 long long。
- 带权路径长度 WPL 是所有叶子的“权值×从根到该叶子的边数”之和。合并费用等于对应哈夫曼树的 WPL。只有一个叶子时经过 0 条边，WPL 和合并费用均为 0；不要混淆边数路径长与上一课“根深度为 1”。

## 五、先做再看：课后自测

1. 仅一堆重 7，答案是多少？2. 四堆都重 1，最少体力是多少？3. 默认 priority_queue 的 top 是最小值吗？

答案：1. 0。2. 2+2+4=8。3. 不是，是最大值。
