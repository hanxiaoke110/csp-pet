# P75｜真题演练（二）

阶段：C4 · 提高。本卡按课堂题板改编格式练习；先复习结构体、模拟、二进制和递归。

## 一、本课要掌握什么

- 把规则转成状态：面额、获得时间、是否使用。
- 严格按“最早的可用票”选择，不能选最大面额或直接取第一张票。
- 用二进制分解整数，并递归格式化指数。

## 二、核心知识卡

公交优惠票同时满足：未使用、时间差 ≤45 分钟、票面额 ≥公交票价。多个符合时取获得最早的那张。

| 记录 | 处理 | 累计费用 |
| --- | --- | --- |
| 地铁 5 元，时刻 1 | 支付 5，记一张票 | 5 |
| 地铁 20 元，时刻 16 | 支付 20，记一张票 | 25 |
| 地铁 7 元，时刻 23 | 支付 7，记一张票 | 32 |
| 公交 18 元，时刻 31 | 消耗时刻 16 的票 | 32 |
| 公交 4 元，时刻 38 | 消耗时刻 1 的票 | 32 |
| 公交 7 元，时刻 68 | 时间差恰为 45，消耗时刻 23 的票 | 32 |

优惠票仅用于公交，坐地铁仍需支付；用过的票不能再次使用。

## 三、完整例题与代码

### 18895｜公交换乘

输入 n，之后每行 op price time；op=0 是地铁，op=1 是公交。保证记录时间严格递增且每分钟最多一条。输出总费用。

```cpp
#include <iostream>
#include <vector>
using namespace std;
struct Ticket { int price, time; bool used; };
int main() {
    int n;
    cin >> n;
    vector<Ticket> tickets;
    int first = 0;
    long long cost = 0;
    for (int i = 0; i < n; ++i) {
        int op, price, time;
        cin >> op >> price >> time;
        while (first < static_cast<int>(tickets.size())
               && time - tickets[first].time > 45) ++first;
        if (op == 0) {
            cost += price;
            tickets.push_back({price, time, false});
        } else {
            bool found = false;
            for (int j = first; j < static_cast<int>(tickets.size()); ++j) {
                if (!tickets[j].used && tickets[j].price >= price) {
                    tickets[j].used = true;
                    found = true;
                    break;
                }
            }
            if (!found) cost += price;
        }
    }
    cout << cost << '\n';
    return 0;
}
```

时间差 >45 才过期；恰好 45 可用。严格递增的整数分钟保证每次公交前有效时间段中最多有 45 张地铁票，所以扫描时间 O(45n)，存票空间 O(n)。若允许同一分钟多条记录，这个时间界限不再成立，要重新选算法。

### 19098｜幂次方

输入 1 ≤ n ≤20000，输出题目约定的 0、2 表示法：2^0 写成 `2(0)`，2^1 写成 `2`，其他指数递归表示，无空格。

137=2^7+2^3+2^0。7=2^2+2+2^0，因此输出 `2(2(2)+2+2(0))+2(2+2(0))+2(0)`。

```cpp
#include <iostream>
using namespace std;
void show(int n) {
    bool first = true;
    for (int k = 14; k >= 0; --k) {
        if ((n & (1 << k)) == 0) continue;
        if (!first) cout << '+';
        first = false;
        if (k == 0) cout << "2(0)";
        else if (k == 1) cout << '2';
        else {
            cout << "2(";
            show(k);
            cout << ')';
        }
    }
}
int main() {
    int n;
    cin >> n;
    show(n);
    cout << '\n';
    return 0;
}
```

20000 小于 2^15，所以扫描位 14 到 0 足够。递归处理的是指数 k，规模迅速减小；时间取决于生成的表达式和各调用扫描位数，不能把它说成只调用一次 O(log n)。

## 四、易错点

- 公交按 `<45` 判断，误排除时间差等于 45 的票。
- 看到最早票面额不足就停止；应该继续找后面的可用票。
- 过期票与使用过的票是两个状态，不能混用。
- 幂次方的 2^1 输出成 2(1)，不符合本题约定；加号不能放首尾。

## 五、先做再看：课后自测

答案：1. 能，差 45。2. 能。3. `2(2+2(0))+2`。
