# P71｜递归算法（二）

阶段：C3 · 进阶。先复习 P70 的递归含义、出口和返回值。

## 一、本课要掌握什么

- 用“最后一步”把方案计数拆成互不重叠的情况。
- 识别重复计算，用记忆化保存状态答案。
- 枚举分解时约定非递减顺序，避免把换序当新方案。

## 二、核心知识卡

楼梯每步走 1 或 2 级。f(n) 表示到达第 n 级的方案数。最后一步来自 n−1 或 n−2，这两种情况不重叠，因此 f(n)=f(n−1)+f(n−2)。

| n | 1 | 2 | 3 | 4 | 5 |
| --- | --- | --- | --- | --- | --- |
| f(n) | 1 | 2 | 3 | 5 | 8 |

普通递归里 f(5) 调 f(4)、f(3)，f(4) 又调 f(3)、f(2)：同一个 f(3) 被算了两遍。记忆化像答案本：第一次计算并记下，以后直接读取。

## 三、完整例题与代码

### 18350｜再爬一次（升级版）

输入 n（1 ≤ n ≤ 50），输出走法数。输入 3，输出 3；输入 50，输出 20365011074，需要 long long。

```cpp
#include <iostream>
using namespace std;
long long memo[51] = {};
long long ways(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    if (memo[n] != 0) return memo[n];
    memo[n] = ways(n - 1) + ways(n - 2);
    return memo[n];
}
int main() {
    int n;
    cin >> n;
    cout << ways(n) << '\n';
    return 0;
}
```

本题所有合法状态答案都大于 0，所以 0 可以表示“未计算”。若别的题答案可能为 0，应另用 visited 数组或不会与答案冲突的标记。记忆化后时间、数组和递归栈均为 O(n)。

### 18352｜数的分解

把正整数 n 写成若干个大于 1 的整数的乘积，因数按非递减顺序排列；单独的 n 本身也算一种。这里以 2 ≤ n ≤ 1000 为演示范围。输入 12，输出 4：12、2×6、3×4、2×2×3。

f(low,rest) 表示剩余乘积 rest、下一因数至少为 low 时的方案数。初始的 1 种方案是“直接选 rest”；继续拆时只枚举 low ≤ d ≤ rest/d 且 d 整除 rest。

```cpp
#include <iostream>
using namespace std;
long long countWays(int low, int rest) {
    long long ans = 1;
    for (int d = low; d <= rest / d; ++d) {
        if (rest % d == 0) ans += countWays(d, rest / d);
    }
    return ans;
}
int main() {
    int n;
    cin >> n;
    cout << countWays(2, n) << '\n';
    return 0;
}
```

递归后 low=d，后续因数不能比 d 小，因此 2×6 与 6×2 不会重复统计。本例是搜索枚举，不承诺像爬楼梯那样 O(n)；范围扩大后应重新评估时间。

## 四、易错点

- f(n−1)+f(n−2) 适用于每步 1 或 2 级；增加 3 级步长后关系式和出口都要改。
- n=50 的结果超过 int；只改数组类型却不改函数返回类型仍会溢出。
- 分解时忘记最小因数限制，会重复计算排列。
- 记忆化键必须覆盖所有影响结果的参数；f(low,rest) 不能只按 rest 缓存。
