# P76｜树（一）

阶段：C4 · 提高。先复习数组、函数、递归和队列。

## 一、本课要掌握什么

- 分清根、父亲、孩子、兄弟、叶子和子树。
- 本课堂约定根的深度为 1，树深度是结点深度的最大值。
- 二叉树最多有两个孩子；“最多两个”不等于“必须两个”。

## 二、核心知识卡

```text
        1
       / \
      2   3
     / \
    4   5
```

根为 1；2 的父亲为 1；4、5 是兄弟；叶子为 3、4、5。结点 4 深度为 3，本图树深度为 3。另一些题定义根深度为 0，做题时必须看题意。

| 遍历 | 访问顺序 | 上图结果 |
| --- | --- | --- |
| 前序 | 根、左、右 | 1 2 4 5 3 |
| 中序 | 左、根、右 | 4 2 5 1 3 |
| 后序 | 左、右、根 | 4 5 2 3 1 |

“根”不是只指整棵树的 1，而是每次递归处理的当前子树根。

## 三、完整例题与代码

### 21256｜找树根和深度

输入 n，随后 n−1 行 x y 表示 y 是 x 的孩子，保证为合法有根树，编号 1 到 n，n ≤10000。输出两行：根编号、深度。n=1 时根为 1，深度为 1。

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>
using namespace std;
int main() {
    int n;
    cin >> n;
    vector<vector<int>> children(n + 1);
    vector<int> parent(n + 1, 0), depth(n + 1, 0);
    for (int i = 1; i < n; ++i) {
        int x, y;
        cin >> x >> y;
        children[x].push_back(y);
        parent[y] = x;
    }
    int root = 1;
    while (parent[root] != 0) ++root;
    queue<int> q;
    q.push(root);
    depth[root] = 1;
    int answer = 1;
    while (!q.empty()) {
        int x = q.front(); q.pop();
        for (int y : children[x]) {
            depth[y] = depth[x] + 1;
            answer = max(answer, depth[y]);
            q.push(y);
        }
    }
    cout << root << '\n' << answer << '\n';
    return 0;
}
```

每条边处理一次，时间、空间均为 O(n)。这里用队列按层访问，避免从每个结点重复沿父亲链计算导致链状树 O(n²)，也避免很深的递归栈。

### 21258｜中序遍历

输入 n，随后 n 行 x l r 表示 x 的左右孩子，0 表示缺少孩子。保证合法二叉树，结点编号为 1 到 n，1 ≤ n ≤1000；根不一定是 1，输入行也不一定按编号顺序。

```cpp
#include <iostream>
#include <vector>
using namespace std;
vector<int> leftChild, rightChild;
bool first = true;
void inorder(int x) {
    if (x == 0) return;
    inorder(leftChild[x]);
    if (!first) cout << ' ';
    first = false;
    cout << x;
    inorder(rightChild[x]);
}
int main() {
    int n;
    cin >> n;
    leftChild.assign(n + 1, 0);
    rightChild.assign(n + 1, 0);
    vector<int> parent(n + 1, 0);
    for (int i = 0; i < n; ++i) {
        int x, l, r;
        cin >> x >> l >> r;
        leftChild[x] = l; rightChild[x] = r;
        if (l) parent[l] = x;
        if (r) parent[r] = x;
    }
    int root = 1;
    while (parent[root] != 0) ++root;
    inorder(root);
    cout << '\n';
    return 0;
}
```

每个结点访问一次，时间 O(n)，数组 O(n)，递归栈 O(h)，h 为树高。若题目允许极深的树，可用显式栈改写遍历。

## 四、易错点

- 默认第一个输入结点就是根。正确做法是找没有父亲的结点。
- 0 是空孩子标记，不是实际结点；递归必须先判断 0。
- 中序遍历只是访问顺序，不保证结果有序；只有二叉搜索树在相应键值规则下才有此性质。
- 求子树人数时必须计入自己：size(x)=1+size(left)+size(right)。
