```
【画面要求】竖版约 1024×1536，儿童友好卡通风信息图，浅色背景。左上角放智子IP吉祥物「小麒麟」（奶白色绒毛、粉白渐变双角与鬃毛、琥珀色大眼睛、金色祥云项圈配蓝宝石吊坠、金色火焰状尾巴尖，开心欢迎姿态）和红色 "C++" 标签，顶部居中大标题「控制结构 知识卡」，标题下是橙色横幅标语（两侧带⭐）。正文由 7 个圆角栏目块组成，每块有序号图标和彩色小标题（红/蓝/绿/紫/橙轮换），底部是红色⚠️「关键提醒」栏，右下角再放一只小麒麟插图（指向知识点的姿态）。

【栏目内容】

一、分支结构 if-else
- 单分支：if (条件) { 语句 }
- 双分支：if (条件) { A } else { B }
- 多分支：else if 链，从上到下逐个判断，满足即执行并跳过后续
代码示例：
int x = 85;
if (x >= 90) cout << "优秀";
else if (x >= 60) cout << "及格";   // 85 → 输出"及格"
else cout << "不及格";
易错点：else 总是和最近的未配对 if 匹配；判断相等用 == 不是 =。

二、多路选择 switch
代码示例：
switch (day) {
  case 1: cout << "周一"; break;
  case 2: cout << "周二"; break;
  default: cout << "其他";
}
要点：case 后必须是整型常量；漏写 break 会"穿透"继续执行下一个 case；default 处理所有未列情况。

三、for 循环
代码示例：
int sum = 0;
for (int i = 1; i <= 100; i++) sum += i;   // 1+2+...+100 = 5050
结构：for (初始化; 条件; 更新) { 循环体 }
执行顺序：初始化(1次) → 条件判断 → 循环体 → 更新 → 条件判断 …
常考：循环执行次数 = 条件满足的次数，注意 < 和 <= 的区别。

四、while 与 do-while
while：先判断后执行，可能一次都不执行
do-while：先执行后判断，至少执行一次
代码示例：
int n = 1234, cnt = 0;
while (n > 0) { cnt++; n /= 10; }   // 统计位数，cnt = 4
典型应用：读数拆位、辗转相除、直到输入 0 结束。

五、break 与 continue
- break：立即跳出整个循环（或 switch）
- continue：跳过本次循环剩余部分，直接进入下一次
代码示例：
for (int i = 1; i <= 10; i++) {
  if (i % 2 == 0) continue;   // 跳过偶数
  if (i > 7) break;           // 到 9 停止
  cout << i << " ";           // 输出 1 3 5 7
}

六、循环嵌套
代码示例：
for (int i = 1; i <= 9; i++) {
  for (int j = 1; j <= i; j++)
    cout << j << "×" << i << "=" << i*j << " ";
  cout << "\n";               // 打印九九乘法表（下三角）
}
要点：外层每执行 1 次，内层完整执行一轮；总次数 = 外层 × 内层；嵌套中 break 只跳出当前所在的那一层。

七、真题常见考法（程序阅读题）
1. 数循环次数：看清初始值、条件、步长（i++ / i+=2）
2. 跟踪变量：列表记录每次循环后各变量的值
3. 条件陷阱：== 写成 =、< 与 <=、&& 与 || 的混淆
4. 输出格式：空格、换行、最后一次是否多输出

⚠️ 关键提醒：
✅ else 与最近的 if 配对，写大括号避免歧义
✅ switch 每个 case 别忘 break
✅ for 循环次数看清 < 还是 <=
✅ while 先判断、do-while 先执行
✅ break 只跳一层，continue 只跳一次
✅ 程序阅读题先列表跟踪变量再作答
```

```
【栏目内容】

一、一维数组
定义与初始化：
int a[100];            // 定义 100 个整型，下标 0~99
int b[5] = {1,2,3,4,5};
int c[5] = {0};        // 全部清零的常用写法
访问：a[i]，下标从 0 开始，最大为 长度-1
遍历模板：
for (int i = 0; i < n; i++) cin >> a[i];
for (int i = 0; i < n; i++) cout << a[i] << " ";

二、二维数组
定义：int g[10][10];   // 10 行 10 列
遍历模板（行优先）：
for (int i = 0; i < n; i++)
  for (int j = 0; j < m; j++)
    cin >> g[i][j];
常考方向：行、列、主对角线(i==j)、副对角线(i+j==n-1)

三、字符数组与字符串
字符数组：char s[105];  以 '\0' 结尾
输入输出：cin >> s（遇空格停）；gets / getline 读整行
C++ string：string str;  支持 + 拼接、== 比较、.size() 长度
遍历：for (int i = 0; i < str.size(); i++)

四、常用字符串函数速查表（表格栏目）
| 功能 | 字符数组(cstring) | string |
| 长度 | strlen(s) | s.size() / s.length() |
| 拷贝 | strcpy(a,b) | a = b |
| 拼接 | strcat(a,b) | a += b 或 a + b |
| 比较 | strcmp(a,b) 返回 0/负/正 | a == b、a < b 直接用 |
| 取子串 | 无内置 | s.substr(pos, len) |
注意：比较结果按字典序（逐字符比 ASCII）。

五、数组三大经典用法
1. 标记数组：bool vis[N];  vis[x]=true 表示 x 出现过（判重、筛法）
2. 桶数组（计数）：int cnt[N];  cnt[x]++ 统计每个值出现次数
3. 前缀和思想：s[i] = s[i-1] + a[i]，O(1) 求区间和
代码示例（桶统计）：
int cnt[26] = {0};
for (int i = 0; s[i]; i++) cnt[s[i]-'a']++;   // 统计字母频次

六、下标与越界（最易错！）
- int a[10] 的合法下标只有 0~9，a[10] 就是越界
- 越界不报错但会读到垃圾值，结果"有时候对有时候错"
- 数组开多大：比题目最大范围多 5~10（如 n≤1000 就开 1010）
- 循环边界 i<n 还是 i<=n，配合下标从 0 还是从 1 想一遍

七、真题常见考法
1. 数组逆序 / 平移 / 插入删除后的输出结果
2. 字符与 ASCII 转换：'a'→97，'0'→48，'A'→65；s[i]-'0' 转数字
3. 大小写转换：±32（'a'-'A'=32）
4. 字符串按字典序比较大小、统计字符次数
5. 二维数组求行列和、对角线和

⚠️ 关键提醒：
✅ 下标从 0 开始，范围 0 ~ 长度-1
✅ 数组要初始化，否则是随机垃圾值
✅ 字符数组别忘 '\0' 结尾
✅ string 用 == 比较，字符数组用 strcmp
✅ 数组开大 5~10，防止边界越界
✅ 'a'-'A'=32，'0'=48，记牢三个 ASCII
```

```
【栏目内容】

一、核心方法：变量跟踪法
读程序不要"想"，要"算"：拿一张纸列出变量表，逐行模拟。
步骤：① 写下所有变量及初值 → ② 每执行一步更新表格 → ③ 循环只算前几轮找规律 → ④ 写出最终输出
示例表头：| 轮次 | i | sum | 说明 |

二、五大常见程序模式（看到就认出来）
1. 累加器：sum += x;   结果通常是求和
2. 计数器：if (条件) cnt++;   统计满足条件的个数
3. 最值：if (x > mx) mx = x;   求最大/最小值
4. 交换逆序：swap 或 t=a;a=b;b=t; 配合双下标实现逆序
5. 标志位：bool flag = true;  用于判断是否全部满足

三、四大高频陷阱（出题人最爱）
1. 整数除法：5/2=2（不是 2.5），-5/2=-2；想保留小数要 *1.0 或 (double)
2. 运算符优先级：a+b>c && d<e 先算比较再算 &&；& 和 &&、| 和 || 不一样
3. 自增自减：i++ 先用后加，++i 先加后用；cout << i++ + ++i 是未定义行为
4. 循环边界：for(i=0;i<n;i++) 执行 n 次；i<=n 执行 n+1 次

四、溢出与数据范围
- int 范围约 ±21 亿（2×10⁹）：10⁵×10⁵ = 10¹⁰ 会溢出
- 累乘、平方、阶乘最容易爆 int，看到就用 long long
- unsigned 下 0-1 会变成超大数
代码示例：
int a = 100000, b = 100000;
long long c = 1LL * a * b;   // 先转 long long 再乘

五、输出格式陷阱
- 空格在行末还是行首；每行末尾有没有换行
- printf("%03d", x) 补前导零；保留两位小数 printf("%.2f", x)
- 最后一次循环是否多输出一个空格/逗号
- cout 输出 double 默认 6 位有效数字

六、模拟实战示例（完整小例题）
int x = 12, y = 0;
while (x > 0) {
  if (x % 2 == 1) y++;
  x /= 2;
}
cout << y;
跟踪：x=12→6→3→1→0，x%2 为 1 出现 2 次 → 输出 2（本质：统计二进制中 1 的个数）

七、考场提速技巧
1. 循环只算前 2~3 轮 + 最后 1 轮，中间找规律
2. 函数题先搞清"输入是什么、返回什么、改了哪个全局变量"
3. 递归题画出调用树，标出每层返回值
4. 选项代入法：把选项代回程序验证，比硬算快
5. 遇到看不懂的变量名，给它起个外号（cnt→计数器）

⚠️ 关键提醒：
✅ 读程序靠纸笔模拟，不靠脑子空想
✅ 整数除法直接舍去小数
✅ i++ 与 ++i 结果不同
✅ 累乘平方先想 long long
✅ 循环次数看清 < 与 <=
✅ 选项代入法是最后的兜底招
```
