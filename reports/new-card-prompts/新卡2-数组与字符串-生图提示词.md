【栏目内容】

一、一维数组
定义与初始化：
int a[100];            // 定义 100 个整型，下标 0~99
int b[5] = {1,2,3,4,5};
int c[5] = {0};        // 全部清零的常用写法
访问：a[i]，下标从 0 开始，最大为 长度-1
遍历模板：
for (int i = 0; i < n; i++) cin >> a[i];
for (int i = 0; i < n; i++) cout << a[i] << " ";

二、二维数组
定义：int g[10][10];   // 10 行 10 列
遍历模板（行优先）：
for (int i = 0; i < n; i++)
  for (int j = 0; j < m; j++)
    cin >> g[i][j];
常考方向：行、列、主对角线(i==j)、副对角线(i+j==n-1)

三、字符数组与字符串
字符数组：char s[105];  以 '\0' 结尾
输入输出：cin >> s（遇空格停）；getline 读整行
C++ string：string str;  支持 + 拼接、== 比较、.size() 长度
遍历：for (int i = 0; i < str.size(); i++)

四、常用字符串函数速查表（表格栏目，3 列：功能 / 字符数组 cstring / string）
长度：strlen(s) ｜ s.size() 或 s.length()
拷贝：strcpy(a,b) ｜ a = b
拼接：strcat(a,b) ｜ a += b 或 a + b
比较：strcmp(a,b) 返回 0/负/正 ｜ a == b、a < b 直接用
取子串：无内置 ｜ s.substr(pos, len)
注意：比较结果按字典序（逐字符比 ASCII）。

五、数组三大经典用法
1. 标记数组：bool vis[N];  vis[x]=true 表示 x 出现过（判重、筛法）
2. 桶数组（计数）：int cnt[N];  cnt[x]++ 统计每个值出现次数
3. 前缀和思想：s[i] = s[i-1] + a[i]，O(1) 求区间和
代码示例（桶统计）：
int cnt[26] = {0};
for (int i = 0; s[i]; i++) cnt[s[i]-'a']++;   // 统计字母频次

六、下标与越界（最易错！）
- int a[10] 的合法下标只有 0~9，a[10] 就是越界
- 越界不报错但会读到垃圾值，结果"有时候对有时候错"
- 数组开多大：比题目最大范围多 5~10（如 n≤1000 就开 1010）
- 循环边界 i<n 还是 i<=n，配合下标从 0 还是从 1 想一遍

七、真题常见考法
1. 数组逆序 / 平移 / 插入删除后的输出结果
2. 字符与 ASCII 转换：'a'→97，'0'→48，'A'→65；s[i]-'0' 转数字
3. 大小写转换：±32（'a'-'A'=32）
4. 字符串按字典序比较大小、统计字符次数
5. 二维数组求行列和、对角线和

⚠️ 关键提醒：
✅ 下标从 0 开始，范围 0 ~ 长度-1
✅ 数组要初始化，否则是随机垃圾值
✅ 字符数组别忘 '\0' 结尾
✅ string 用 == 比较，字符数组用 strcmp
✅ 数组开大 5~10，防止边界越界
✅ 'a'-'A'=32，'0'=48，记牢三个 ASCII
